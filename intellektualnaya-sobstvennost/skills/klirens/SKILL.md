# /klirens

Оценивает риск столкновения **до** вложений в бренд. Это не заключение «знак свободен» и
не замена профессионального поиска патентного поверенного.

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/intellektualnaya-sobstvennost/CLAUDE.md`.
Файла нет или остались `[ЗАПОЛНИТЬ]` — стоп: «Плагину нужна настройка, запусти
`/intellektualnaya-sobstvennost:cold-start-interview`».

## Шаг 1. Зафиксируй, что именно чистим

- обозначение (слово, логотип, комбинированное, звук — разные оси сравнения);
- товары и услуги, не «вообще бренд»;
- территория (РФ / Мадрид / иная);
- планируется ли регистрация или только использование.

Без перечня товаров клиренс бессмысленен: один и тот же словесный элемент живёт в разных
классах у разных лиц.

## Шаг 2. Где искать

Минимум, который скилл обязан назвать и, если есть доступ в сеть, пройти:

1. открытые реестры Роспатента / ФИПС по товарным знакам и заявкам (включая живые заявки
   с более ранним приоритетом — они тоже основание отказа, ст. 1483);
2. общеизвестные товарные знаки (перечень Роспатента);
3. наименования мест происхождения / географические указания;
4. ЕГРЮЛ на тождественные фирменные наименования в той же сфере (ст. 1474);
5. домены .ru / .рф и очевидные зоны, где клиент будет в сети
   (`/intellektualnaya-sobstvennost:domeny`);
6. фактическое использование в обороте (маркетплейсы, реклама) — незарегистрированное
   обозначение не даёт исключительного права на знак, но даёт риск введения в заблуждение
   и спор о коммерческом обозначении (ст. 1538–1539).

Плагин работает в режиме paste-source / открытый поиск. Платного доступа к профессиональным
базам нет — скажи об этом в выводе: полный поиск поверенного этот прогон не заменяет.

## Шаг 3. Как сравнивать — не «буква в букву»

Отказ и нарушение строятся на **тождестве либо сходстве до степени смешения** у
однородных товаров (ст. 1483, 1484). Сравнивай по трём осям: фонетика, графика, семантика.
Однородность товаров — не равенство номеров классов МКТУ: классы — удобная сетка, суд и
экспертиза смотрят назначение, круг потребителей, каналы сбыта.

Сильнее охраняется: фантазийное слово, серия знаков, известность. Слабее: описательное,
распространённое корневое. Не делай вывод «отличаются одной буквой — свободно»: для
коротких фантазийных это как раз типичный отказ.

Противопоставляются не только свидетельства, но и **более ранние заявки**. «У них ещё не
зарегистрировано» — не очистка.

## Шаг 4. Вердикт — три цвета, без гарантии

| Вердикт | Когда |
|---|---|
| 🟢 низкий | прямых тождеств и близких сходств по однородным товарам в открытых реестрах нет |
| 🟡 средний | есть сходные знаки в соседних классах / слабые описательные / домен занят без знака |
| 🔴 высокий | тождество или очевидное сходство в тех же или однородных товарах; общеизвестный знак |

Любой 🟢 держи с оговоркой: поиск неполный, заявки могли быть поданы вчера, изобразительный
поиск по словесному запросу слеп.

Если цель — регистрация, после клиренса веди `tovarnyj-znak`. Если цель — запуск без заявки,
назови риск, что регистрация уйдёт другому.

## Формат вывода

```markdown
## Клиренс: [обозначение] / [товары]

**Поиск:** [что просмотрено / чего не было]
**Противопоставления:** [номер, класс, почему сходно или нет]
**Вердикт:** [🟢 / 🟡 / 🔴]
**Это не заключение поверенного:** да
**Дальше:** [подавать / менять обозначение / сужать перечень / проверить домен]
```

## Чего не делать

- Не писать «обозначение свободно».
- Не чистить только точные совпадения.
- Не игнорировать живые заявки.
- Не заменять клиренс оценкой «нам нравится / рынок уже нас знает».
- Не проводить patent FTO — это другой объект и другой скилл (в этой фазе его нет).
