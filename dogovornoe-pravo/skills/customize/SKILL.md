# /customize

## Когда запускается
Пользователь ввёл `/dogovornoe-pravo:customize` — хочет изменить что-то в профиле практики (риск, контакт эскалации, позицию плейбука, юрисдикцию, формат вывода) без перезапуска cold-start и без ручной правки.

## Что делать

1. **Прочитай конфиг** `~/.claude/plugins/config/claude-for-legal-ru/dogovornoe-pravo/CLAUDE.md` (и `~/.claude/plugins/config/claude-for-legal-ru/company-profile.md` уровнем выше). Если конфига нет или в нём плейсхолдеры:
   > Настройка ещё не запускалась. Сначала `/dogovornoe-pravo:cold-start-interview` — customize правит уже существующий профиль.

2. **Покажи карту настраиваемого** с текущими значениями одной строкой:
   - **Компания / кто мы** — наименование, ОПФ, отрасль, режим налогообложения, тип практики, ориентация исполнитель/заказчик *(общее для всех плагинов — меняется в `company-profile.md`)*
   - **Аппетит к риску** — консервативный / средний / агрессивный
   - **Люди** — цепочка эскалации, согласующие по порогам суммы и по типу условия
   - **Позиции плейбука** — ответственность (реальный ущерб/упущенная выгода/умысел; возмещение потерь по ст. 406.1 — отдельная позиция), неустойка, обеспечение, расчёты/НДС, права на РИД, ПД, срок/расторжение, применимое право/подсудность, и запасные варианты
   - **Триаж NDA** — что GREEN/YELLOW/RED; уровень защиты раздельно: ноу-хау (ст. 1465 ГК) / режим КТ (ст. 10 ФЗ-98) / только договорная конфиденциальность
   - **Настройки ревью** — стиль правок, глубина пояснений, делать ли сводку для бизнеса по умолчанию
   - **Стиль** — формат документа, канал уведомлений о сроках, формат журнала отклонений
   - **Рабочие пространства дел** — пути, активное дело, кросс-контекст
   - **Интеграции** — Диск / чат / статус, запасные варианты

3. **Спроси, что менять:**
   > Что поправить? Выберите секцию или опишите изменение своими словами.

4. **Внеси точечное изменение** в конфиг, покажи diff «было → стало», подтверди. Не трогай другие секции. Если меняется общая для плагинов сущность (компания) — правь в `company-profile.md` и предупреди, что изменение затронет все плагины форка.

5. **Подтверди:** «Готово. `[секция]`: было `[X]` → стало `[Y]`. Остальное не тронул.»

## Пример
```
/dogovornoe-pravo:customize
Подними порог согласования старшим юристом до 5 млн ₽
```
