# /escalation-flagger

Называет согласующего для проблемы по договору по матрице эскалации конфига и составляет сообщение, чтобы не писать «есть минутка?» в 18:00.

## Инструкции

1. **Загрузи конфиг → `## Эскалация`.** Если пусто/расплывчато — скажи: это должно было зафиксироваться на cold-start; профиль надо дополнить.
2. **Определи сторону** (заказчик/исполнитель) — условие, нормальное на одной стороне, может быть жёстким «нет» на другой.
3. **Охарактеризуй проблему:** порог по сумме / отклонение условия / авто-триггер / бизнес-решение.
4. **Сопоставь с матрицей, назови согласующего** — конкретное лицо/роль, не «руководство юр. функции».
5. **Составь обращение** по шаблону ниже. **Не отправляй** — покажи, отправит юрист.

## Шаблон обращения

```markdown
**Кому:** [ФИО/роль из матрицы]
**Тема:** Согласование — [Контрагент] [тип договора] — [нужное решение]

[1 предложение контекста: какой договор, какая сумма, на какой мы стороне.]

**Вопрос:** [что именно нужно решить].

**Что говорит договор:**
> «[цитата пункта]»

**Что говорит наш плейбук:** [позиция + ссылка на норму ГК, если есть]

**Риск:** 🔴/🟠/🟡 — [1 фраза: чем грозит]

**Опции:**
1. [Опция A] — [последствие]. ← рекомендую, потому что [причина]
2. [Опция B] — [последствие]
3. [Опция C — выйти из сделки, если применимо]

**Нужно решение до:** [дата — с оглядкой на срок ответа на оферту/претензию, если есть]
```

## Что важно для РФ

- Авто-эскалация независимо от суммы (из конфига): безлимитная ответственность; попытка исключить ответственность за умысел (п. 4 ст. 401 ГК — ничтожно); отчуждение исключительных прав от нас; иностранное право/иностранный арбитраж; штрафная неустойка непропорционального размера; любой пункт из списка «никогда».
- **Безлимитное возмещение потерь по ст. 406.1 ГК.** Отдельный триггер, не сводимый к «безлимитной ответственности»: возмещение потерь наступает **без нарушения обязательства и без вины**, и суд его **не снизит** — ст. 333 ГК к нему не применяется (кроме умышленного содействия увеличению потерь, п. 2 ст. 406.1). Привычный предохранитель «суд срежет» здесь не работает.
- **Обработка ПД без поручения по ч. 3 ст. 6 ФЗ-152, либо лимит ответственности ниже потенциального штрафа по ст. 13.11 КоАП.** С 30.05.2025 (ФЗ от 30.11.2024 № 420-ФЗ) повторная утечка — оборотный штраф 1–3 % совокупной выручки, но не менее 20 млн ₽: лимит «не более цены договора» такой риск не покрывает. `[суммы сверять на дату применения]`
- **Иностранный арбитраж при санкционном статусе любой из сторон** — ст. 248.1, 248.2 АПК (исключительная компетенция арбитражных судов РФ, антиисковый запрет). Оговорка может оказаться неисполнимой в обе стороны.
- Если проблема — про подсудность/третейскую оговорку, отметь это в обращении: смена подсудности меняет стоимость и сроки спора.
- **Преддоговорная стадия (ст. 434.1 ГК).** Если эскалация означает выход из длительных переговоров, сопровождавшихся раскрытием информации или расходами контрагента, — отметь в обращении риск претензии по п. 2, 3 ст. 434.1 (недобросовестное прерывание переговоров) и предложи оформить выход письменно с указанием причин.

## Примеры
```
/dogovornoe-pravo:escalation-flagger
В договоре с «Ромашка» безлимитная ответственность — кто согласует и что писать?
```
```
/dogovornoe-pravo:escalation-flagger
Ссылка: romashka-review-memo.md
Проблема: п. 8.2 — исключение упущенной выгоды
```
