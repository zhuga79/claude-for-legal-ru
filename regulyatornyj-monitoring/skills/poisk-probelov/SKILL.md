# /poisk-probelov

## Назначение

Мост между «акт изменился» и «что конкретно открывать». Без этого шага юрист
вручную перебирает весь портфель ЛНА и на глаз решает, какие затронуты — что
на практике означает пропущенные документы.

Результат — приоритизированный список ЛНА для `policy-diff`, а не готовая правка.
Ничего не переписывает.

## Контекст

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/regulyatornyj-monitoring/CLAUDE.md`.
Файла нет или в нём `[ЗАПОЛНИТЬ]` — стоп: запусти
`/regulyatornyj-monitoring:cold-start-interview`.

Список внутренних политик и где они лежат — из раздела «Внутренние политики, с
которыми сверяем» этого конфига. Текст самих политик в git-репозиторий плагина
не копировать — только путь и вывод.

## Когда запускать

После того как `monitoring` пометил акт 🔴 (вступивший, бьёт в watchlist), и
до `policy-diff`: сначала пойми, какие ЛНА вообще задевает акт, потом делай
построчный дифф по каждому из них.

## Шаг 1. Список ЛНА

Возьми из конфига весь перечень, который сверяем, — не только тот документ,
что первым пришёл в голову.

## Шаг 2. Скан каждого ЛНА на изменившуюся норму

Для каждого документа ищи:
- прямую цитату статьи/пункта акта;
- косвенную ссылку (термин, понятие из акта без прямой цитаты);
- смысловое совпадение — тема пересекается, даже если цитаты нет.

Без совпадения любого из трёх видов — документ не задет, дальше не разбирай.

## Шаг 3. Классификация

Та же корзина, что и в `policy-diff`, — чтобы вывод одного скилла читался как
вход другого:

| Корзина | Смысл |
|---|---|
| 🔴 расхождение | ЛНА, судя по всему, требует или запрещает иначе, чем акт после изменения |
| 🟡 дыра | акт ввёл обязательство, в ЛНА темы нет |
| 🟢 не задето | акт про другое; в отчёт попадает только для полноты списка |

Это предварительная оценка по совпадению, не построчный дифф — точную формулировку
и цитату даёт `policy-diff`.

## Шаг 4. Отчёт триажа

```markdown
## Триаж пробелов: [акт]

**Акт:** [реквизиты, pravo.gov.ru, дата вступления]
**Дата триажа:** [ДД.ММ.ГГГГ]

| ЛНА | Корзина | Что похоже задето | Приоритет |
|---|---|---|---|
| … | 🔴/🟡/🟢 | … | 🔴 срочно / 🟡 в очередь / 🟢 не нужно |

**Дальше:** по каждому 🔴/🟡 — `/regulyatornyj-monitoring:policy-diff` для
построчного диффа и цитаты; после диффа, если нужна правка текста —
`/regulyatornyj-monitoring:pererabotka-politiki`.
```

## Чего не делать

- Не давать построчный дифф с цитатами здесь — это `policy-diff`.
- Не предлагать новый текст ЛНА — это `pererabotka-politiki`, и только после
  решения человека, какие документы вообще править.
- Не засчитывать расхождение по смысловому совпадению без последующей проверки
  цитатой — триаж отбирает кандидатов, не подтверждает нарушение.
- Не поднимать письмо ведомства до статуса акта, требующего правки ЛНА:
  триажим только вступившие акты pravo.gov.ru и, отдельной пометкой, проекты
  regulation.gov.ru как ранний сигнал.
- Если акт про ПДн — не делай тут ПДн-специфичный gap-анализ, это
  `personalnye-dannye:reg-gap-analysis`; здесь только общий кросс-контурный
  триаж портфеля.
