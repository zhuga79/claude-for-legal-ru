# /sroki-obsuzhdeniya

Считает, живо ли окно обсуждения. Не пишет текст «официальной позиции Российской Федерации».

## Контекст

Прочитай профиль. Если дело заведено — срок в реестр с пометкой
`[расчёт агента — подтвердить человеком]`.

## Шаг 1. Возьми даты с карточки, не из памяти

С карточки `regulation.gov.ru` сними: вид проекта (ФЗ / постановление / приказ / иное);
дату размещения; дату начала и окончания обсуждения; стадию (уведомление / текст проекта /
завершено).

Типовой ориентир ПП от 25.08.2012 № 851: для проекта НПА, **кроме проекта федерального
закона**, срок общественного обсуждения — **15 календарных дней**; для проекта ФЗ на
портале действует свой срок, указанный в карточке и в постановлении
`[15 дней — из устойчивых цитат ПП 851; перед дедлайном перечитай карточку и актуальную
редакцию 851/96/373]`.

Не подставляй 15 дней, если карточка пишет другой интервал. Не путай обсуждение
уведомления о разработке и обсуждение текста проекта — это разные окна.

ПП № 96 (ОРВ) и ПП № 373 (антикоррупционная экспертиза) — **другие** процедуры на том же
портале, их сроки не складывать со сроком общественного обсуждения по ПП № 851; даты окна
брать только с карточки проекта.

## Шаг 2. Что можно успеть

В окно кладут замечания через портал (или так, как написано в карточке). Это **не**
официальный отзыв органа власти и не заключение комитета Госдумы.

После окончания разработчик по правилам 851 размещает сводку предложений в свой срок
(ориентир — до 60 календарных дней). Сводка не обязывает принять замечание.

Проект могут снять, заменить, внести в Госдуму в другой редакции. Дедлайн обсуждения ≠
дата вступления закона.

## Шаг 3. Когда окно уже закрыто

Скажи прямо: обсуждение кончилось. Дальше — следить за внесением / опубликованием
(`monitoring`), а не «подать замечание задним числом на портал».

Если нужен отзыв на уже внесённый законопроект — это лоббистская / ассоциационная
работа, не этот скилл.

## Формат вывода

```markdown
## Обсуждение: [проект]

**Карточка:** [ссылка]
**Вид акта:** [ФЗ / ПП / приказ]
**Окно:** с [дата] по [дата] `[с карточки; не из памяти]`
**Статус:** [открыто — осталось N дней / закрыто]
**Что успеваем:** [замечание на портал / ничего]
**Не путать с:** [вступление в силу / отзыв на законопроект в Думе]
```

## Чего не делать

- Не считать срок по аналогии с NPRM (60 дней и т. п.).
- Не обещать, что замечание изменят закон.
- Не писать отзыв от имени государственного органа.
- Не применять закрытый проект как действующую норму.
