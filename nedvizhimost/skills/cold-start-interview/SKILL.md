# /cold-start-interview

Пишет `~/.claude/plugins/config/claude-for-legal-ru/nedvizhimost/CLAUDE.md` по структуре
шаблона плагина. Повтор с `--redo` — переинтервью с показом diff до перезаписи.

## Инструкции

1. **Проверь состояние конфига.** Есть `[ЗАПОЛНИТЬ]` — свежее интервью. Заполнен и `--redo` не
   передан — спроси, перезапускать ли.
2. **Веди по блокам, один блок за раз.** Записывай ответы словами пользователя.
3. **Прочитай `company-profile.md`** уровнем выше, если он есть: наименование, ОПФ повторно не
   спрашивай.
4. **Запиши конфиг**, создав родительские папки. Покажи сводку: «Вот что я услышал — что понял
   неверно?»

## Сценарий

### Блок 1. Роль и тип объектов

- Наша роль в сделках: покупатель / продавец / арендатор / арендодатель / застройщик /
  подрядчик / outside-адвокат, сопровождающий сделку?
- Основной тип объектов: жилая недвижимость / коммерческая недвижимость / земельные участки /
  промышленная недвижимость / доли в строительстве по ДДУ?

  *Роль меняет вывод по каждому скиллу: интерес покупателя и продавца расходятся по цене и
  срокам оплаты, интерес застройщика и дольщика — по неустойке и эскроу, интерес арендатора и
  арендодателя — по индексации и основаниям расторжения.*

### Блок 2. Текущий портфель

- Объекты в собственности?
- Объекты, которые мы арендуем (мы — арендатор)?
- Объекты, сданные нами в аренду (мы — арендодатель)?
- Открытые сделки на данный момент?

### Блок 3. Ключевое для каждого скилла (не пропускать)

- Известен ли актуальный статус моратория на неустойку по 214-ФЗ на **текущую** дату? Если
  нет — предупреди: статус менялся трижды за 2022-2026 годы отдельными постановлениями
  Правительства, последнее известное состояние на 2026-08-26 — мораторий на начисление снят
  с 01.01.2026, но выплата по старым требованиям может быть отсрочена до конца 2026 года
  `[сверить действующее постановление на дату вопроса]`.
- Работаем ли с эскроу-счетами (обязательны по 214-ФЗ с 2019 года, с 01.03.2025 — также для
  подряда на ИЖС)?

### Блок 4. Outside-консультанты

- Outside-адвокат ФПА для недвижимости?
- Кадастровый инженер (определение границ, перепланировки)?
- Нотариус (для сделок, требующих нотариальной формы — например, доли в общей собственности)?
- Риелтор-партнёр, если есть?

### Блок 5. Позиции практики

- Порог материальности, при котором сделка эскалируется outside-адвокату ФПА (сумма сделки)?
- Аппетит к риску: консервативный (comprehensive due diligence по каждой сделке) / средний
  (стандартная проверка, outside-адвокат для материальных сделок) / агрессивный?

  *Агрессивная позиция при сделках с недвижимостью рискованнее, чем в большинстве других
  контуров: дефект в проверке даёт необратимый результат — утрату права собственности или
  обременение, перешедшее вместе с объектом, а не просто предмет для последующего спора.*

- Что никогда не делаем? (например, «не подписываем ДДУ без проверки застройщика по реестру
  проблемных объектов»)

### Блок 6. Ведение дел

- Портфель ведёт плагин `vedenie-del`. Включить режим сейчас?

  *Сроки в сделках с недвижимостью короткие: срок на снятие ареста/ипотеки до закрытия,
  срок регистрации в ЕГРН, срок на предъявление претензии по гарантии. Режим снижает риск
  пропуска.*

### Блок 7. Что болит

- Что в практике по недвижимости отнимает больше всего времени: проверка застройщика,
  анализ обременений, договоры аренды, приёмка по гарантии?
- Был ли за последние два года эпизод, когда обременение или дефект договора всплыли уже
  после подписания?

## После интервью

Предложи проверочный прогон: «Дайте проект договора или опишите объект сделки — покажу, что
вижу». Напомни, что каждый вывод плагина — проект для проверки практикующим юристом, и что
перед опорой на конкретные ставки, сроки и госпошлины плагин обязан свериться по
первоисточнику — эта область права меняется постановлениями Правительства чаще, чем раз в
год.
