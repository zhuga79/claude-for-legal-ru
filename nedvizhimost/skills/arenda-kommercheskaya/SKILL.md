# Проверка договора коммерческой аренды

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nedvizhimost/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nedvizhimost:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — сроки регистрации и продления пиши в
реестр дела.

## Вводные перед началом

- Сторона: мы арендатор или арендодатель?
- Объект: офис / склад / торговое помещение / смешанное назначение
- Планируемый срок аренды
- Ставка

## Шаг 1. Проверка объекта и прав арендодателя

```markdown
## Проверка объекта
- [ ] Проверка по кадастру выполнена (`/nedvizhimost:proverka-kadastra`)
- [ ] Адрес и площадь точно идентифицированы
- [ ] Назначение помещения соответствует планируемому использованию
- [ ] Проверка обременений выполнена (`/nedvizhimost:analiz-obremenenij`)

## Права арендодателя
- [ ] Право собственности (если арендодатель — собственник) — по выписке ЕГРН
- [ ] Либо право сдавать в субаренду (если арендодатель — субарендодатель) — выписка ЕГРН +
      основной договор аренды + согласие собственника на субаренду
- [ ] Если арендодатель — юрлицо: устав, полномочия подписанта
- [ ] Если арендодатель — физлицо в браке: нотариальное согласие супруга для аренды свыше года
```

## Шаг 2. Проверка условий договора

### A. Срок

- **Срок аренды:** [...]
- **Регистрация в ЕГРН (ст. 609 ГК):** обязательна для срока свыше 1 года
  - Госпошлина (подп. 27.2 ст. 333.33 НК РФ, ставка действует с 01.01.2025): **4 000 ₽** для
    физлиц, **44 000 ₽** для организаций — плоская ставка, без порога по кадастровой стоимости
    (в отличие от пошлины за регистрацию права собственности); за регистрацию соглашения об
    изменении или расторжении договора аренды — 700 ₽ / 2 000 ₽ соответственно `[сверено
    2026-08-27 по тексту НК РФ]`
  - Без регистрации договор не имеет силы для третьих лиц
  - Распространённый обход — заключение на 11 месяцев с автоматическим продлением (формально
    не запускает требование регистрации; юридически рискованный приём — суд может
    переквалифицировать серию таких договоров при систематическом использовании)
- [ ] Срок свыше 1 года? — планировать регистрацию
- [ ] Срок до 1 года? — регистрация не требуется
- [ ] Условия продления — учтено преимущественное право (ст. 621 ГК)

### B. Арендная плата

- **Ставка:** [₽/м²/мес.]
- **Структура:** базовая ставка; НДС (если арендодатель — плательщик НДС, обычно юрлицо на
  ОСНО); коммунальные расходы — включены или отдельно; эксплуатационные расходы (CAM);
  капитальный ремонт — по умолчанию несёт арендодатель (ст. 616 ГК)
- **Индексация:** ежегодная в процентах, либо привязка к ИПЦ, либо фиксированный график
  повышения; предел индексации; дата первой индексации

Риск: ставка указана только в USD/EUR — для резидентов РФ обязательство должно быть в рублях
(ст. 317 ГК допускает валютную оговорку с расчётом в рублях, но не обязательство,
исполняемое в иностранной валюте на территории РФ, кроме ограниченных случаев).

### C. Обеспечительный платёж

В российском праве нет формального института security deposit в англо-американском смысле.
Используются:

- **Обеспечительный платёж** (ст. 381.1 ГК) — удерживается арендодателем, возвращается при
  окончании аренды без нарушений, может быть зачтён в счёт платы за последний месяц
- **Задаток** — иной, более жёсткий механизм
- **Аванс** — простейшая форма

- [ ] Структура обеспечения ясна
- [ ] Условия возврата прописаны
- [ ] Право арендодателя удерживать компенсацию за ущерб определено

### D. Ограничения использования

- [ ] Назначение помещения соответствует планируемому использованию
- [ ] Субаренда — разрешена ли (по умолчанию по ГК — с согласия арендодателя)
- [ ] Использование аффилированными лицами
- [ ] Изменения помещения (перепланировка) — какие согласования нужны
- [ ] Вывески и реклама — ограничения
- [ ] Часы работы (для торговых помещений и общепита)

### E. Содержание и ремонт

По умолчанию (ст. 616 ГК): капитальный ремонт — за счёт арендодателя; текущий ремонт и
содержание — за счёт арендатора. Договор может изменить это распределение:

- [ ] Кто несёт какие виды ремонта
- [ ] Замена инженерных систем (отопление, кондиционирование)
- [ ] Места общего пользования в бизнес-центре
- [ ] Эксплуатационные расходы (CAM)
- [ ] Охрана и парковка

### F. Расторжение

**Право арендатора.** По ГК (ст. 620) — только через суд по установленным основаниям
(правило по умолчанию). В договоре обычно предусматриваются дополнительные основания и право
одностороннего отказа:

- [ ] С уведомлением (типично 3-6 месяцев)
- [ ] Без указания причины (с платой за досрочный отказ)
- [ ] По определённым причинам без платы (смена контроля, продажа объекта и т.п.)

**Право арендодателя.** По ГК (ст. 619) — только через суд по установленным основаниям.
В договоре:

- [ ] При неуплате аренды свыше N месяцев
- [ ] При нарушении назначения использования
- [ ] При нарушении ограничений на субаренду
- [ ] Иные основания

- [ ] Сроки уведомления — не слишком короткие и не чрезмерно длинные
- [ ] Последствия расторжения: возврат объекта в оговорённом состоянии, финальный расчёт,
      возврат обеспечительного платежа

### G. Страхование и ответственность

- [ ] Страхование объекта — обязанность арендодателя
- [ ] Страхование имущества арендатора — обязанность арендатора
- [ ] Страхование ответственности арендатора — арендодатель вправе потребовать
- [ ] Взаимное возмещение убытков (страховые случаи vs небрежность)

### H. Форс-мажор

- [ ] Стандартная оговорка о форс-мажоре (война, стихийные бедствия, акты органов власти)
- [ ] Санкционная оговорка — формулировки расходятся, явная формулировка предпочтительнее
- [ ] Положения на случай эпидемиологических ограничений
- [ ] Требования к уведомлению о форс-мажоре

## Шаг 3. Специфика РФ

**Ловушка 1. Аренда у физлица vs юрлица.** Арендодатель-физлицо обязан платить НДФЛ 13% (или
15%) с дохода от аренды; часто арендодатель хочет, чтобы арендатор удерживал и перечислял
налог как агент — такая договорённость требует отдельной проверки правовых оснований.

**Ловушка 2. Цепочки субаренды.** Длинные цепочки аренды умножают риск при проблеме у прямого
арендодателя — проверять права по всей цепочке.

**Ловушка 3. Государственное/муниципальное имущество.** Особый порядок (ст. 17, 17.1 ФЗ-135
«О защите конкуренции») — как правило, только через торги `[проверить по первоисточнику]`.

**Ловушка 4. Аренда земли под уже существующим строением.** Отдельная схема, если здание в
собственности, а земля — в аренде; при продаже здания — вопрос судьбы права на землю (ст. 272
ГК, ст. 39.20 ЗК).

**Ловушка 5. Изменение целевого назначения.** Использование не по документам — риск требований
о переоформлении разрешительной документации и связанных затрат.

## Чего не делает

- Не ведёт переговоры — это задача бизнеса и outside-адвоката.
- Не регистрирует договор в ЕГРН — это нотариус или Росреестр.
- Не проводит полное due diligence объекта — для этого `/nedvizhimost:proverka-kadastra` и
  `/nedvizhimost:analiz-obremenenij`.

Каждый вывод этого скилла — проект для проверки практикующим юристом.
