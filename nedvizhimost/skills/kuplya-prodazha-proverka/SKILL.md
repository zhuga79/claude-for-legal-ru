# Проверка договора купли-продажи недвижимости

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nedvizhimost/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nedvizhimost:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — сроки закрытия сделки и регистрации
пиши в реестр дела.

## Вводные перед началом

- `/nedvizhimost:proverka-kadastra` выполнена
- `/nedvizhimost:analiz-obremenenij` выполнена — все обременения выявлены, урегулирование
  спланировано
- Известна сторона, которую представляем (покупатель / продавец)

Отличие от ДДУ (`/nedvizhimost:ddu-proverka`) — здесь объект уже существует, это не покупка на
этапе строительства.

## Обязательные условия договора (ст. 554-555 ГК, ФЗ-218)

Договор купли-продажи недвижимости должен содержать:

1. Определение конкретного объекта (адрес, площадь, кадастровый номер)
2. Цену (ст. 555 ГК — обязательное условие для договоров купли-продажи недвижимости)
3. Условие о регистрации перехода права в ЕГРН (обязательна по ст. 131 ГК и ФЗ-218)

Без этих условий договор не считается заключённым.

## Шаг 1. Проверка обязательных условий

- [ ] Объект описан конкретно (кадастровый номер, адрес, площадь)
- [ ] Цена указана конкретно
- [ ] Условия оплаты (когда и как)
- [ ] Условия передачи объекта и подписания передаточного акта
- [ ] Регистрация перехода права в ЕГРН предусмотрена

## Шаг 2. Проверка условий договора

### A. Цена и условия оплаты

- **Цена:** [сумма]
- **Структура оплаты:** наличные при подписании / эскроу до регистрации (рекомендуется для
  покупателя) / аккредитив банка / безналичный расчёт на счёт продавца / часть — ипотечные
  средства / часть — материнский капитал
- **Момент оплаты:** до подписания (редко) / при подписании / после регистрации перехода в
  ЕГРН (предпочтительно для покупателя) / эскроу до регистрации (предпочтительно для продавца
  при недоверии к платёжеспособности)
- **Валюта:** только рубли для резидентов РФ (ст. 317 ГК — обязательство в иностранной валюте
  на территории РФ допустимо только в ограниченных случаях)

Критично для покупателя: не платить до регистрации перехода права в ЕГРН без защитных
механизмов (эскроу). Критично для продавца: не передавать объект до получения оплаты.

### B. Условие о передаче

- Дата фактической передачи объекта покупателю (не только документальной)
- Обязательное составление передаточного акта (ст. 556 ГК)
- Состояние объекта на момент передачи
- Включённое имущество (если продаётся с мебелью/техникой)
- Порядок расчёта по коммунальным задолженностям (до даты передачи — продавец, после —
  покупатель)
- Передача ключей

Риск для покупателя: отсутствие чёткой даты передачи, формулировка «передача в течение N дней
с момента регистрации» без конкретики.

### C. Налоги и расходы

- Госпошлина за регистрацию перехода права — обычно платит покупатель. `[сверено 2026-08-27]`
  С реформой, действующей с 01.01.2025 (подп. 22 п. 1 ст. 333.33 НК РФ), пошлина **пороговая, не
  плоская:** для физлиц — **4 000 ₽** при кадастровой стоимости объекта до 20 млн ₽ включительно,
  свыше — 0,02% кадастровой стоимости (мин. 0,02% цены сделки, макс. 500 000 ₽); для юрлиц —
  **44 000 ₽** при кадастровой стоимости до 22 млн ₽ включительно, свыше — 0,2% кадастровой
  стоимости (мин. 0,2% цены сделки, макс. 1 000 000 ₽). Для дорогих объектов (переговорных
  диапазонов коммерческой недвижимости) считать по формуле, не по плоской ставке. Прежние
  плоские 2 000 / 22 000 ₽ больше не актуальны — см. `references/currency-watch.md`, п. 4
- Услуги риелтора — платит обычно продавец на открытом рынке, иначе по договорённости
- НДФЛ продавца: 13% / 15% (при совокупном годовом доходе свыше 5 млн ₽); освобождение при
  владении свыше 5 лет для большинства случаев (ст. 217.1 НК), свыше 3 лет для отдельных
  оснований (наследство, приватизация, дарение от близкого родственника); налоговая база — не
  ниже кадастровой стоимости × 0,7, если фактическая цена меньше (ст. 214.10 НК)
  `[проверить по первоисточнику — этот блок не сверялся в текущей сессии, см.
  references/currency-watch.md, п. 5]`

Риск: договорная цена искусственно занижена с целью уклонения от НДФЛ — незаконно и рискованно
для покупателя (при последующем оспаривании сделки взыскание может ограничиться заниженной
суммой).

### D. Заверения и гарантии продавца

Стандартные: продавец — полноправный собственник; право не ограничено; обременений, кроме
раскрытых, нет; открытых споров и притязаний третьих лиц нет; коммунальные платежи оплачены
(или раскрыты как задолженность); зарегистрированных третьих лиц без права прекращения
регистрации нет (или раскрыто); нет режима совместной собственности с супругом без согласия.

Дополнительно могут включаться: соответствие данных кадастра фактическим характеристикам;
отсутствие несогласованных перепланировок; отсутствие задолженности по налогам и штрафам.

### E. Ответственность при истребовании (ст. 461 ГК)

Продавец отвечает за изъятие объекта у покупателя третьим лицом по основанию, возникшему до
сделки. Условие об этом стоит формулировать явно, а не полагаться на диспозитивную норму по
умолчанию.

### F. Расторжение

Основания — общие по ГК. Если покупка с ипотекой и она не одобрена — риск для продавца. Если
оплата не поступила после регистрации — риск для продавца (отмена регистрации затруднена).
Рекомендация: эскроу для защиты покупателя до регистрации; требование подтверждения оплаты до
передачи объекта — для защиты продавца.

## Шаг 3. Особые сценарии

**Покупка с ипотекой.** Банк проверяет объект отдельно — дополнительный уровень защиты; банк
требует эскроу; может требоваться титульное страхование (обычно на 3 года); банк выступает
стороной или наблюдателем сделки.

**Материнский капитал.** Дополнительные требования (согласование с Социальным фондом), доли
детям должны быть выделены; дополнительная документация.

**Доли в общей собственности.** Обязательно нотариальное удостоверение (ст. 42 ФЗ-218);
действует преимущественное право других сособственников на выкуп доли (ст. 250 ГК — срок
30 дней); нотариус сопровождает подачу документов в Росреестр.

**Покупатель-иностранец.** Ограничения на покупку земельных участков в приграничных районах
(указ Президента и ЗК РФ); применимость специальных ограничительных указов для лиц из
недружественных государств — проверять на дату сделки; дополнительные требования к
документации.

**Несовершеннолетние сособственники.** Требуется согласие органа опеки и попечительства;
обязательно предоставление равноценного имущества несовершеннолетнему взамен отчуждаемой доли.

**Продавец — ИП или юридическое лицо.** НДС применим к коммерческой недвижимости при продавце
на ОСНО, не применим к жилой; при крупности сделки или заинтересованности могут требоваться
корпоративные одобрения — см. `korporativnoe-pravo:odobrenie-sdelki`.

## Чего не делает

- Не сопровождает ипотечную сделку — это отдельный банковский процесс.
- Не проводит нотариальное удостоверение — это нотариус.
- Не подаёт документы в Росреестр — это нотариус или сами стороны.

Каждый вывод этого скилла — проект для проверки практикующим юристом.
