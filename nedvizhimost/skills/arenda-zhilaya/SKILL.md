# Проверка договора найма жилого помещения

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nedvizhimost/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nedvizhimost:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — срок найма, срок предупреждения о
расторжении и налоговый режим наймодателя пиши в реестр дела.

## Кто использует

- Наниматель (арендатор жилья)
- Наймодатель (собственник, сдающий жильё)
- Управляющая компания при работе с портфелем объектов

## Два разных договора — определи применимый вид до начала проверки

### Вид 1. Договор найма жилого помещения (ст. 671 ГК)

Наиболее частый случай для сдачи жилья гражданином гражданину. Регулируется специальными
нормами гл. 35 ГК — у нанимателя усиленная защита (см. раздел F ниже), которой нет в обычной
аренде.

### Вид 2. Договор аренды жилого помещения (ст. 606 ГК)

Применяется, если наймодатель или наниматель — юридическое лицо (например, компания снимает
квартиру для проживания сотрудника, или собственник — юрлицо). Действует общий режим аренды,
без специальной защиты нанимателя по ст. 687-688 ГК — юридическое лицо не может проживать в
помещении само, оно вправе использовать его только для проживания граждан (ст. 671 ч. 2 ГК),
и совокупность прав здесь ближе к обычной коммерческой аренде.

→ Всегда фиксируй в начале анализа, какой вид применим — от этого зависит объём защиты стороны.

## Шаг 1. Проверка прав наймодателя

```markdown
- [ ] Выписка ЕГРН подтверждает право собственности наймодателя
- [ ] Если несколько собственников — согласие всех сособственников на сдачу внаём
- [ ] Если наймодатель состоит в браке, а объект — совместная собственность — нотариальное
      согласие супруга рекомендуется, хотя закон формально не всегда требует его для найма
      (в отличие от отчуждения) `[проверить по первоисточнику — конкретика зависит от
      обременения и режима собственности]`
- [ ] Если есть несовершеннолетние сособственники — согласие органа опеки требуется для
      действий, затрагивающих их долю
- [ ] Если объект в ипотеке — проверить, требует ли договор с банком согласия залогодержателя
      на сдачу внаём (типовое условие ипотечных договоров, не общее правило закона)
```

## Шаг 2. Проверка объекта

```markdown
- [ ] Адрес и площадь совпадают с выпиской ЕГРН
- [ ] Состояние объекта задокументировано — акт приёма-передачи с фотофиксацией рекомендуется
- [ ] Имущество, входящее в комплект (мебель/техника), описано в приложении
- [ ] Порядок доступа и передачи ключей зафиксирован
```

## Шаг 3. Критичные условия договора

### A. Срок

```markdown
- **Срок найма:** [...]
- **Максимальный/умолчательный срок по закону (ст. 683 ГК):** договор найма заключается на
  срок не более 5 лет; если срок в договоре не определён, договор считается заключённым на
  5 лет `[сверено 2026-08-27]`
- **Краткосрочный наём (до 1 года)** — отдельный режим по ст. 683 ч. 2 ГК: часть гарантий
  нанимателю (право на вселение других лиц, преимущественное право на продление в общем
  порядке) применяется в усечённом виде, если стороны прямо не указали иное
- **Регистрация обременения в ЕГРН** — обязательна для найма, заключённого на срок **не менее
  года** (порядок установлен ФЗ-218 «О государственной регистрации недвижимости», а не ст. 609
  ГК — та регулирует аренду, а не наём между гражданами) `[сверено 2026-08-27]`. Заявление на
  регистрацию подают стороны договора; наймодатель, не являющийся собственником, обязан
  подтвердить право на заключение договора отдельными документами.

⚠ Распространённая практика — заключать договор на 11 месяцев с последующим переоформлением —
формально не запускает требование о регистрации (срок меньше года). Юридический эффект такой
практики для целей защиты нанимателя по ст. 687-688 ГК не меняется — эти нормы применяются к
любому найму жилого помещения, включая краткосрочный, хотя отдельные гарантии по нему уже
(см. ст. 683 ч. 2 ГК).
```

### B. Плата за наём

```markdown
- **Ежемесячная плата:** [сумма]
- **Срок внесения платы:** [число месяца]
- **Способ оплаты:** реквизиты счёта / наличные / перевод через платёжный сервис
- **Индексация:** для найма между физлицами обычно отсутствует; если предусмотрена — указать
  формулу и периодичность
- **Что включено:** только плата за наём / плата за наём + коммунальные платежи / отдельно
- **Что не включено:** как правило, счётчики электроэнергии, воды, газа — оплачивает наниматель
  по показаниям, если не указано иное
- **Пени/неустойка за просрочку** — размер должен быть соразмерным, право суда снизить
  чрезмерную неустойку по ст. 333 ГК сохраняется независимо от формулировки договора
```

### C. Обеспечительный платёж

```markdown
- **Сумма** (типично — плата за один месяц)
- **Правовая основа** — обеспечительный платёж (ст. 381.1 ГК): вносится в обеспечение
  денежного обязательства и может засчитываться в счёт его исполнения при наступлении
  предусмотренных договором обстоятельств
- [ ] Условия возврата при отсутствии претензий по состоянию имущества прописаны
- [ ] Условие о праве наймодателя удерживать компенсацию за причинённый ущерб — с обязанностью
      документально подтвердить размер ущерба, а не удерживать произвольно
- [ ] Возможность зачёта платежа в счёт оплаты последнего месяца — только по обоюдному согласию
```

### D. Порядок пользования и ограничения

```markdown
- [ ] Круг лиц, имеющих право проживать (только заявленные наниматели, или допускается
      вселение иных граждан с согласия наймодателя — ст. 679 ГК)
- [ ] Регистрация по месту жительства/пребывания — постоянная или временная, условие в
      договоре есть или отсутствует
- [ ] Домашние животные — разрешены/запрещены, ограничения
- [ ] Курение
- [ ] Гости — ограничения по продолжительности проживания
- [ ] Переустройство/перепланировка — какие согласования нужны
```

### E. Содержание и ремонт (ст. 681 ГК)

```markdown
По умолчанию:
- **Текущий ремонт** — обязанность нанимателя, если договором не установлено иное
- **Капитальный ремонт** — обязанность наймодателя, если договором не установлено иное
`[сверено 2026-08-27]`

Договор может изменить это распределение — проверить, не переложена ли на нанимателя
обязанность по капитальному ремонту без адекватной компенсации (снижение платы, зачёт затрат).

- [ ] Кто несёт расходы на замену вышедшей из строя техники
- [ ] Порядок уведомления о неисправностях инженерных систем
- [ ] Переустройство дома, в котором находится помещение, существенно меняющее условия
      пользования — не допускается без согласия нанимателя (ст. 681 ч. 3 ГК)
```

### F. Расторжение — сильная защита нанимателя (ст. 687-688 ГК)

```markdown
### Право нанимателя
- Наниматель вправе расторгнуть договор в любое время с письменным предупреждением
  наймодателя за **3 месяца** (ст. 687 ч. 1 ГК)

### Право наймодателя — только через суд, ограниченный перечень оснований
- Невнесение платы за наём: за 6 месяцев подряд для срока найма свыше года, либо более двух
  раз подряд по истечении срока платежа для краткосрочного найма (если договором не
  установлен более длительный срок) — ст. 687 ч. 2 ГК
- Разрушение или порча жилого помещения нанимателем или другими гражданами, за действия
  которых он отвечает
- Использование помещения не по назначению или систематическое нарушение прав и интересов
  соседей — после предупреждения наймодателя и непринятия мер к устранению нарушений

### Отсрочка при разрушении/порче или систематическом нарушении прав соседей
Суд вправе предоставить нанимателю срок не более **1 года** для устранения нарушений,
послуживших основанием для иска. Если нарушения не устранены — по повторному обращению
наймодателя суд принимает решение о расторжении договора; по просьбе нанимателя суд может
отсрочить исполнение решения на срок не более **1 года** `[сверено 2026-08-27]`.

### Последствия расторжения
При отказе освободить помещение добровольно — выселение производится в судебном порядке
(ст. 688 ГК, с последующим исполнительным производством по ФЗ-229).

- [ ] Договор не пытается обойти императивные гарантии ст. 687 ГК условием о внесудебном
      расторжении по инициативе наймодателя — такое условие не подлежит применению
- [ ] Сроки уведомления в договоре не короче установленных законом там, где закон их фиксирует
```

### G. Регистрация по месту жительства/пребывания

```markdown
- Наниматель вправе требовать временной регистрации по месту пребывания; постоянная —
  только с согласия наймодателя
- Наймодатель обязан уведомить территориальный орган МВД о проживании иностранных граждан и
  лиц без гражданства
- Отсутствие регистрации создаёт нанимателю практические сложности (полис ОМС, запись
  ребёнка в школу/детский сад по месту жительства и т.п.)

- [ ] Условие о регистрации в договоре — есть/нет
- [ ] Если нет — явно предупредить нанимателя, что это ограничивает его практические
      возможности
```

### H. Разрешение споров, типичные паттерны

```markdown
#### Паттерн 1. Наймодатель удерживает обеспечительный платёж без основания
Наниматель вправе требовать возврата в суде; бремя доказывания размера ущерба — на
наймодателе.

#### Паттерн 2. Наймодатель пытается расторгнуть договор досрочно во внесудебном порядке
Если основания не соответствуют ст. 687 ГК — наниматель вправе оспорить, защита сильная
именно потому, что закон не даёт наймодателю права на односторонний отказ вне суда, за
исключением случаев, прямо предусмотренных договором в рамках допустимого законом.

#### Паттерн 3. Некачественное жильё
Наниматель вправе требовать уменьшения платы или устранения недостатков по ст. 681 ГК;
дополнительно применяется Закон РФ № 2300-1 «О защите прав потребителей», если наймодатель
действует как ИП или юрлицо (не для найма между гражданами напрямую).

#### Паттерн 4. Незаявленные жильцы / субнаём без согласия
Наймодатель вправе требовать прекращения — доказывание факта постоянного проживания на
практике затруднено без содействия соседей или управляющей компании.
```

## Шаг 4. Налоги наймодателя-физлица

```markdown
| Режим | Ставка | Плюсы | Минусы |
|---|---|---|---|
| НДФЛ (по умолчанию, без специального статуса) | 13% / 15% при доходе свыше 5 млн ₽/год | не требует регистрации | подача декларации 3-НДФЛ, ставка выше остальных вариантов |
| НПД для самозанятого | 4% при сдаче внаём физлицу, 6% — юрлицу | низкая ставка, простая регистрация через приложение «Мой налог» | лимит дохода **2,4 млн ₽/год** — при превышении статус самозанятого прекращается автоматически `[сверено 2026-08-27 — лимит не менялся]` |
| ИП на УСН «доходы» 6% | 6% от дохода | можно уменьшить налог на страховые взносы | требует регистрации ИП, отчётности, обязательных страховых взносов независимо от дохода |

Для долгосрочной сдачи жилья физлицом НПД обычно наиболее эффективен по ставке при доходе в
пределах лимита. Если наймодатель — клиент, для которого налоговый вопрос материален —
эскалировать точный расчёт в `nalogovoe-pravo` (`tax-advisor` считает налог, этот скилл — нет).
```

## Чего не делает

- Не оформляет регистрацию по месту жительства/пребывания — это МВД.
- Не проводит осмотр объекта — нужен личный осмотр нанимателем/наймодателем или их
  представителем.
- Не считает точный налог наймодателя — общий ориентир по режиму, точный расчёт и подача
  отчётности — зона `nalogovoe-pravo`.
- Не заменяет outside-адвоката ФПА для материальных или спорных случаев (встречается редко
  для простого найма жилья, но не исключено при крупной сумме или конфликте сторон).

---

Проверки перед выдачей:
- [ ] Вид договора (наём vs аренда с участием юрлица) определён верно — от этого зависит объём
      защиты по ст. 687-688 ГК
- [ ] Условия расторжения по инициативе наймодателя сверены с исчерпывающим перечнем оснований
      ст. 687 ГК, а не приняты по формулировке договора
- [ ] Обязательность регистрации обременения в ЕГРН оценена по фактическому сроку договора
- [ ] Утверждения без сверки по первоисточнику помечены `[проверить по первоисточнику]`

Каждый вывод этого скилла — проект для проверки практикующим юристом.
