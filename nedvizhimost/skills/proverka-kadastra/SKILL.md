# Проверка объекта по кадастру

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nedvizhimost/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nedvizhimost:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — результаты проверки и дату выписки
пиши в реестр дела.

## Вводные перед началом

- Кадастровый номер, либо адрес, либо данные предполагаемого собственника
- Ожидаемая стоимость платной выписки — порядка 290-460 ₽ через Росреестр
  `[проверить по первоисточнику — актуальный размер платы]`
- Срок получения: электронно — минуты; на бумаге — 3-5 рабочих дней
  `[проверить по первоисточнику]`

## Что можно проверить по ЕГРН

### A. Данные объекта
Точный адрес; площадь (общая, для квартир — жилая); этажность, год постройки; назначение
(жилое / нежилое / промышленное / иное); кадастровая стоимость.

### B. Права
Текущий собственник (физическое или юридическое лицо); дата и основание возникновения права;
доли (если несколько собственников); история переходов права (последние сделки).

### C. Обременения
Ипотека (с указанием банка-залогодержателя); зарегистрированная аренда; сервитут; арест или
запрет регистрационных действий; доверительное управление; иное.

### D. Кадастровая стоимость
Текущее значение; дата определения; возможность оспаривания через комиссию Росреестра или суд.

## Шаг 1. Получить выписку из ЕГРН

**Каналы:** сайт Росреестра (rosreestr.gov.ru) — предпочтительно; портал Госуслуг — проще для
физлиц; МФЦ — бумажная выписка с печатью; данные Публичной кадастровой карты — бесплатно, через
`mcp__ru-rosreestr__search_object_by_address` / `search_object_by_cadastre` /
`get_object_details` / `get_encumbrances` / `get_cadastre_value`, если коннектор подключён.
Важно: данные ПКК — справочные и бесплатные, это не полная выписка ЕГРН с подтверждёнными
правами и обременениями; для юридически значимой проверки перед сделкой платная выписка через
Росреестр/Госуслуги остаётся обязательной (см. `.mcp.json` этого плагина).

**Виды выписок:** об основных характеристиках и правах (типовая); о переходе прав (история
переходов); о кадастровой стоимости (для оспаривания); полная информация (платная, все
категории); об обременениях (точечная); расширенная (специальные цели).

## Шаг 2. Анализ данных объекта

```markdown
## Данные объекта
- Кадастровый номер: [...]
- Адрес: [...]
- Точное соответствие адресу, указанному в сделке: [да/нет]
- Назначение: [жилое / нежилое / иное]
- Площадь: общая [X м²] / жилая [Y м²]
- Этаж / этажность: [...]
- Год постройки: [...]
- Кадастровая стоимость: [сумма]

## Соответствие планируемой сделке
- [ ] Площадь совпадает
- [ ] Назначение совпадает (жилое для жилого — норма; нежилое, продаваемое под видом жилого —
      флаг, см. про апартаменты в `/nedvizhimost:ddu-proverka`)
- [ ] Адрес совпадает
```

## Шаг 3. Проверка прав

```markdown
## Права
- Текущий собственник(и): [ФИО / наименование]
- Доли: [если несколько собственников]
- Дата приобретения: [ДД.ММ.ГГГГ]
- Основание (договор, наследство, приватизация и т.д.): [...]

### Соответствие продавцу / стороне сделки
- [ ] Имя совпадает точно
- [ ] Все собственники установлены
- [ ] Если собственник состоит в браке — нужно согласие супруга на отчуждение

### История переходов (если запрошена эта выписка)
- Последние сделки — обычный характер или подозрительно частая смена собственника?
- Залоговые операции
- Сделки моложе 3 лет — возможны последствия по НДФЛ продавца (для физлиц) или по банкротству,
  если применимо
```

## Шаг 4. Проверка обременений

```markdown
## Ипотека
- Есть? [да/нет]
- Банк-залогодержатель: [...]
- Дата регистрации: [...]
- Влияние на сделку:
  - При покупке — нужно согласие банка-залогодержателя либо полное погашение
  - При аренде — банк может оспорить сделку

## Аренда (зарегистрированная)
- Есть? [да/нет]
- Срок: [...] · Арендатор: [...]
- Влияние: при продаже покупатель получает объект с существующим арендатором (если аренда не
  прекращается); действует преимущественное право арендатора на продление (ст. 621 ГК)

## Сервитут
- Есть? [да/нет — обычно для земельных участков]
- В чьих интересах: [...]
- Влияние: ограничивает использование объекта

## Арест / запрет регистрационных действий
- Есть? [да/нет — критично]
- Кто наложил: [ФССП / суд / следователь]
- Основание: [...]
- Влияние: **сделка невозможна до снятия**

## Доверительное управление
- Есть? [да/нет]
- Управляющий: [...]
```

Критично: при наличии ареста или запрета — сделка невозможна до снятия, любое дальнейшее
рассмотрение сделки без урегулирования этого вопроса бессмысленно.

## Шаг 5. Анализ кадастровой стоимости

```markdown
- Текущая стоимость: [сумма]
- Дата определения: [ДД.ММ.ГГГГ]

### Значение
- Налог на имущество — база
- НДФЛ при продаже (для физлиц) — если фактическая цена ниже 70% кадастровой стоимости,
  налоговая база принудительно считается как кадастровая стоимость × 0,7 (ст. 214.10 НК)
  `[проверить по первоисточнику — номер статьи и коэффициент]`
- Госпошлина за регистрацию — с реформы 01.01.2025 зависит и от субъекта регистрации, и от
  кадастровой стоимости объекта: плоская ставка (4 000 ₽ физлицо / 44 000 ₽ юрлицо) действует
  только до порога (20/22 млн ₽ соответственно), выше — 0,02%/0,2% кадастровой стоимости
  `[сверено 2026-08-27 — см. CLAUDE.md и references/currency-watch.md, п. 4]`

### Если оценка завышена
Может быть оспорена через комиссию Росреестра или суд; снижение уменьшает налог на имущество и
может увеличить чистую выручку при продаже. Основание — ст. 22 ФЗ-237 «О государственной
кадастровой оценке» `[проверить по первоисточнику]`.
```

## Шаг 6. Оценка рисков

```markdown
## Критично (стоп)
- Арест или запрет регистрационных действий
- Несоответствие собственника заявленному продавцу
- Объект в реестре проблемных застройщиков (для новостроек)
- Кадастровая стоимость отсутствует или равна нулю — возможны проблемы с регистрацией

## Существенно
- Ипотека без согласия банка
- Аренда, неизвестная продавцу
- Частая смена собственников в истории
- Несоответствие площади или иных характеристик

## Приемлемо
- Чистая история
- Один устойчивый собственник длительное время
- Обременений нет
- Данные кадастра согласованы
```

## Дополнительные возможности ЕГРН

Уведомления об изменениях записи объекта — через Госуслуги или личный кабинет Росреестра,
полезно для долгосрочного мониторинга. Сводная выписка о всех объектах недвижимости заявителя
в РФ — для управления собственным портфелем.

## Формат вывода

```markdown
# Проверка по кадастру — [объект]

## Данные объекта
[подтверждено]

## Права
- Собственник: [...]
- Совпадает с заявленным продавцом: [да/нет]

## Обременения
[перечень с оценкой по каждому типу]

## Кадастровая стоимость
- Текущая: [...]
- Значение для налога / цены

## Красные флаги
[перечень]

## Вывод
[ЧИСТО / ПРОДОЛЖАТЬ ПРИ УСЛОВИЯХ / НЕ ПРОДОЛЖАТЬ]

## Рекомендуемые действия
- [ ] Получить обновлённую выписку перед закрытием сделки (не старше 30 дней)
- [ ] Урегулировать [конкретное обременение]
- [ ] Получить согласие [...], если применимо
```

## Чего не делает

- Не проводит полное due diligence сверх кадастровой проверки — для этого отдельный скилл
  `/nedvizhimost:analiz-obremenenij`.
- Не регистрирует сделку — это нотариус / Росреестр.
- Не оспаривает кадастровую стоимость — это outside-адвокат совместно с комиссией Росреестра
  или судом.

Каждый вывод этого скилла — проект для проверки практикующим юристом.
