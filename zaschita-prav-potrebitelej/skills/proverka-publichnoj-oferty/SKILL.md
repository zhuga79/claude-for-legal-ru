# /proverka-publichnoj-oferty

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/zaschita-prav-potrebitelej/CLAUDE.md`.
Файла нет или в нём `[ЗАПОЛНИТЬ]` — стоп, направь на
`/zaschita-prav-potrebitelej:cold-start-interview`.

**Гейт.** Этот скилл проверяет проект оферты/условий, которые бизнес готовится
опубликовать сам, — ревью со стороны продавца/исполнителя перед публикацией, а не
разбор того, нарушает ли уже опубликованная чужая оферта права конкретного потребителя.

## Назначение

Проверить проект оферты перед публикацией: выявить условия, недействительные как
ущемляющие права потребителя, отсутствующие обязательные элементы, пробелы по типу
продукта.

## Workflow

### Шаг 1. Определи тип документа

| Тип | Структура | Основная норма |
|---|---|---|
| Публичная оферта (ст. 437 ГК) | условия доступа к товару/услуге для любого обратившегося потребителя | ЗоЗПП + ГК |
| Лицензионное соглашение (EULA) | условия использования ПО/приложения | ст. 1235 и след. ГК (часть четвёртая) |
| Публичный договор (ст. 426 ГК) | обязанность заключить договор с каждым обратившимся на равных условиях | ЗоЗПП + отраслевое регулирование |
| Договор присоединения (ст. 428 ГК) | типовые условия без индивидуального согласования | ЗоЗПП |

### Шаг 2. Обязательные элементы (ст. 10 ЗоЗПП — для B2C)

- [ ] **Информация о продавце/исполнителе:** полное фирменное наименование, ОГРН/ИНН,
      адрес места нахождения
- [ ] **Цена** — окончательная, с учётом НДС там, где применимо, без скрытых доплат
- [ ] **Существенные условия** — описание товара/услуги, характеристики
- [ ] **Срок исполнения/поставки** или порядок его определения
- [ ] **Гарантия**, если применима
- [ ] **Условия и порядок оплаты**, включая право выбора между наличной и безналичной
      формой (ст. 16.1 ЗоЗПП)
- [ ] **Контактная информация** для обращений и жалоб

### Шаг 3. Условия, недействительные как ущемляющие права потребителя (ст. 16 ЗоЗПП)

Недопустимые условия договора, ущемляющие права потребителя по сравнению с правилами,
установленными законом или иными нормативными правовыми актами РФ, **ничтожны** — вне
зависимости от того, согласился ли потребитель на них при заключении договора
`[сверено 2026-08-27]`. При предъявлении потребителем требования об исключении такого
условия оно рассматривается продавцом в течение 10 дней.

| Условие в проекте | Почему недействительно |
|---|---|
| «Споры рассматриваются только судом по месту нахождения продавца» | ст. 17 ЗоЗПП — подсудность по выбору потребителя (по месту нахождения продавца / по месту жительства потребителя / по месту заключения или исполнения договора), это правило нельзя сузить договором |
| «Возврат денег — только бонусами/промокодами» | ст. 18 ЗоЗПП — потребитель вправе требовать возврата уплаченной денежной суммы |
| «Продавец не отвечает за качество товара» | противоречит ст. 4, 18 ЗоЗПП |
| «Оплата — только безналично / только наличными, без выбора» | ст. 16.1 ЗоЗПП — обязательна возможность выбора |
| «Условия договора продавец меняет в одностороннем порядке без уведомления» | ст. 310 ГК — одностороннее изменение обязательства не допускается, если иное прямо не предусмотрено законом или договором для этого случая |
| «Согласие на любую обработку персональных данных» без конкретизации целей | 152-ФЗ, ст. 9 — согласие должно быть конкретным, предметным, информированным |
| Возрастная маркировка контента занижена против фактического содержания | ФЗ от 29.12.2010 № 436-ФЗ |
| «Товар нельзя вернуть ни при каких условиях» | ст. 18, 25, 26.1 ЗоЗПП — право на возврат императивно там, где эти статьи применимы |

→ Такое условие потребитель вправе требовать исключить из договора; ничтожность
наступает независимо от факта клика «согласен».

### Шаг 4. Пробелы по типу продукта

#### SaaS / цифровой продукт

- [ ] Период отказа от товара, приобретённого дистанционно (аналогия со ст. 26.1 ЗоЗПП)
- [ ] Условия лицензии, если есть собственная интеллектуальная собственность (ст. 1235 ГК)
- [ ] Уровень доступности сервиса (SLA), если заявлен
- [ ] Порядок выгрузки/переноса данных пользователя
- [ ] Порядок и последствия прекращения договора

#### Маркетплейс

- [ ] Разграничение ролей: оператор маркетплейса vs продавец — кто отвечает перед
      потребителем за конкретное нарушение
- [ ] Порядок возврата товара через маркетплейс, включая переадресацию требования продавцу
- [ ] Порядок разрешения споров между потребителем, продавцом и оператором

#### Финансовые продукты

- [ ] Указание на лицензию/статус в реестре Банка России, если применимо
- [ ] Раскрытие полной стоимости кредита (ст. 6 ФЗ от 21.12.2013 № 353-ФЗ)
- [ ] Период отказа: 14 дней для кредита (ст. 11 ФЗ № 353-ФЗ), «период охлаждения» для
      страхования согласно действующему Указанию Банка России `[проверить по
      первоисточнику на дату вопроса]`

## Чего не делает

- Не составляет оферту с нуля — это задача outside-специалиста.
- Не настраивает механизм принятия оферты (клик, ЭДО) — это продуктовая команда.
- Не заменяет квалифицированное ревью для продукта с высоким регуляторным риском.
