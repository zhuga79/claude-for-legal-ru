# /proverka-pered-zapuskom

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/zaschita-prav-potrebitelej/CLAUDE.md`.
Файла нет или в нём `[ЗАПОЛНИТЬ]` — стоп, направь на
`/zaschita-prav-potrebitelej:cold-start-interview`.

**Гейт.** Этот скилл проверяет то, что публикует сама компания (продавец, исполнитель,
владелец маркетплейса), перед выходом в свет. Если запрос на самом деле о том, что
потребитель хочет оспорить чужой запущенный продукт или предъявить претензию, — это не
этот скилл: см. `## Роль` в CLAUDE.md и переключись на `sudebnyj-process`.

Если включён режим `vedenie-del` — заведи срез по продукту/запуску и веди список
действий с дедлайнами там, а не в памяти диалога.

## Назначение

Комплексный pre-launch обзор потребительского продукта: вывод — решение о готовности к
запуску (GO / GO с условиями / НЕ ЗАПУСКАТЬ) плюс список действий с дедлайнами.

## Предварительно нужно знать

- Продукт готов минимум до MVP, понятна модель продажи (свой сайт / приложение / через
  маркетплейс / офлайн)
- Известна плановая дата запуска
- Из профиля ясны сектор и применимые регуляторы

## Категории проверки

### A. ЗоЗПП — базовое раскрытие информации и возврат

```markdown
- [ ] Информация о продавце: полное наименование, ОГРН/ИНН, адрес места нахождения — видна на
      сайте/в карточке (ст. 10 ЗоЗПП)
- [ ] Цена окончательная, без скрытых доплат на последнем шаге оформления (ст. 10 ЗоЗПП)
- [ ] Характеристики товара, срок годности/службы, гарантийный срок, изготовитель — указаны
      (ст. 10 ЗоЗПП)
- [ ] Для дистанционной продажи — полный состав обязательной информации до заключения договора
      предоставлен в письменной форме при доставке (ст. 26.1 ЗоЗПП) — от этого зависит, какой
      срок возврата действует: 7 дней или 3 месяца
- [ ] Политика возврата опубликована и не противоречит ст. 18/25/26.1/32 ЗоЗПП — отдельно прогони
      `/zaschita-prav-potrebitelej:proverka-politiki-vozvrata`
- [ ] Дистанционный способ возврата товара надлежащего качества предложен наравне с личной явкой
      (Постановление КС РФ от 17.02.2026 № 7-П) — не только «приезжайте в пункт выдачи»
- [ ] Контакты для жалоб + информация о праве обратиться в территориальный орган
      Роспотребнадзора видны потребителю
```

### B. Персональные данные (152-ФЗ) — верхнеуровневый флаг

Полный аудит 152-ФЗ — зона плагина `personalnye-dannye`, не этого скилла. Здесь —
только проверка, что база для запуска не создаёт очевидного риска:

```markdown
- [ ] Политика обработки ПДн опубликована и доступна на сайте
- [ ] Согласие на обработку собирается до, а не после сбора данных
- [ ] Если данные обрабатываются несовершеннолетних — отдельное согласие законного
      представителя (152-ФЗ, ст. 9)
- [ ] Если планируется трансграничная передача — вопрос требует отдельного ревью:
      эскалировать в `personalnye-dannye` до запуска, не решать здесь
```

Нашли на этом шаге серьёзный пробел (нет политики, нет согласий) — это не «минус» в
общем зачёте, а отдельный show-stopper с передачей на `personalnye-dannye`.

### C. Реклама (38-ФЗ) — верхнеуровневый флаг

Отдельного контура рекламного права в форке нет; здесь — только базовые риски:

```markdown
- [ ] Рекламные материалы не содержат абсолютных/непроверяемых заявлений («лучший»,
      «единственный», «100% безопасно» без подтверждения)
- [ ] Если товар/услуга из категории со специальными требованиями к рекламе (финансы,
      медицина/БАД, алкоголь, азартные игры) — отдельная сверка обязательна, здесь не
      закрывается
- [ ] Таргетинг рекламы не дискриминирует по признакам, запрещённым ст. 5 ФЗ «О рекламе»
- [ ] Маркировка интернет-рекламы (токен ОРД) настроена, если реклама размещается в интернете
      `[проверить по первоисточнику — режим маркировки менялся]`
```

### D. Интеллектуальная собственность

```markdown
- [ ] Собственный товарный знак — статус регистрации известен (см.
      `intellektualnaya-sobstvennost:tovarnyj-znak`)
- [ ] Используемые чужие изображения/шрифты/музыка — лицензированы, права подтверждены
- [ ] Открытый исходный код в продукте — соответствие лицензиям проверено
- [ ] Клиренс по классам МКТУ перед выходом под новым брендом — см.
      `intellektualnaya-sobstvennost:klirens`
```

### E. Отраслевой оверлей

В зависимости от сектора — применимые регуляторы и требования:

| Сектор | Регулятор | Ключевое требование |
|---|---|---|
| Финансовые услуги | Банк России | лицензия/уведомление, раскрытие полной стоимости |
| Медицина / БАД | Минздрав / Росздравнадзор | регистрация, обязательные оговорки о противопоказаниях |
| Образование | Минобрнауки / Рособрнадзор | лицензия, аккредитация (если выдаётся диплом) |
| Алкоголь / табак | Росалкогольрегулирование | лицензия, возрастной контроль, дистанционная продажа алкоголя ограничена |
| Азартные игры | уполномоченные органы | лицензия, ограничение мест и способов продажи |
| ПО для госзаказа | Минцифры | реестр российского ПО |

Совпадение с одним из секторов — не закрывается этим скиллом полностью, только
флагается как открытый пункт для профильного консультанта.

### F. Возрастные ограничения

```markdown
- [ ] Контент 18+ — есть возрастной ценз на входе (age gate)
- [ ] Контент иных возрастных категорий (16+/12+/6+/0+) — маркировка видна на витрине/упаковке
      согласно ФЗ от 29.12.2010 № 436-ФЗ «О защите детей от информации, причиняющей вред их
      здоровью и развитию»
- [ ] Сбор ПДн несовершеннолетних — согласие законного представителя (152-ФЗ ст. 9)
```

### G. Платежи и чеки

```markdown
- [ ] Потребителю доступен выбор между наличной и безналичной оплатой, цена не различается
      по способу оплаты (ст. 16.1 ЗоЗПП)
- [ ] Итоговая цена видна потребителю до оплаты, без скрытых доплат
- [ ] Кассовый чек формируется по каждой продаже (ФЗ от 22.05.2003 № 54-ФЗ «О применении ККТ»)
- [ ] Для трансграничных платежей — санкционный скрининг проведён (см. `противодействие
      отмыванию`, если применимо к бизнесу)
```

### H. Поддержка и жалобы

```markdown
- [ ] Канал для обращений и жалоб виден на сайте/в приложении
- [ ] Срок ответа на письменную претензию соответствует практике по ЗоЗПП (обычно 10 дней —
      срок для конкретного требования проверяется по применимой статье, единого 10-дневного
      срока на любую претензию закон не устанавливает `[проверить по конкретной норме]`)
- [ ] Потребитель проинформирован, что подсудность иска — по его выбору (ст. 17 ЗоЗПП: по месту
      нахождения продавца / по месту жительства потребителя / по месту заключения или
      исполнения договора) и это условие в оферте нельзя сузить договором
```

### Шаг 3. Оценка критичности по каждому пункту

## Сквозные ссылки

- `zaschita-prav-potrebitelej:proverka-politiki-vozvrata` — детальный разбор политики возврата
- `zaschita-prav-potrebitelej:proverka-publichnoj-oferty` — детальный разбор оферты/условий
- `personalnye-dannye` — полный 152-ФЗ-комплаенс (согласия, локализация, поручения)
- `intellektualnaya-sobstvennost:klirens`, `:tovarnyj-znak` — бренд и товарный знак
- `vedenie-del` — реестр действий и сроков по запуску

## Чего не делает

- Не публикует оферту/политику от имени бизнеса — нужно решение уполномоченного лица.
- Не заменяет полный аудит 152-ФЗ и полный ревью рекламной кампании — только флагает риски
  верхнего уровня.
- Не заменяет отраслевую лицензионную экспертизу.
