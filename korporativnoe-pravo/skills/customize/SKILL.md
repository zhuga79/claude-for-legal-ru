# /customize

## Когда запускается
Пользователь ввёл `/korporativnoe-pravo:customize` — хочет изменить что-то в профиле
корпоративной практики без перезапуска cold-start и без ручной правки конфига.

## Что делать

1. **Прочитай конфиг** `~/.claude/plugins/config/claude-for-legal-ru/korporativnoe-pravo/CLAUDE.md`
   (и `~/.claude/plugins/config/claude-for-legal-ru/company-profile.md` уровнем выше). Если
   конфига нет или в нём плейсхолдеры:
   > Настройка ещё не запускалась. Сначала `/korporativnoe-pravo:cold-start-interview` —
   > customize правит уже существующий профиль.

2. **Покажи карту настраиваемого** с текущими значениями одной строкой:
   - **Компания / кто мы** — наименование, ОПФ *(общее для всех плагинов — меняется в
     `company-profile.md`)*
   - **Чьи вопросы ведём** — само общество / участник / совет директоров / приобретатель доли
   - **Устройство общества** — ОПФ (ООО / АО), число участников, тип устава (типовой / свой),
     положения об одобрении сделок, преимущественное право, ограничения полномочий директора
   - **Открытые процедуры** — ОСУ/ОСА в подготовке, сделки на одобрении, DD, корпоративный спор,
     регистрационные действия в ЕГРЮЛ, по каждому — стадия
   - **Позиции практики** — порог эскалации outside-адвокату, кто ведёт корпоративный учёт
   - **Ведение дел** — режим, активное дело (живёт в `dela/_sostoyanie.md`)

3. **Спроси, что менять:**
   > Что поправить? Выберите секцию или опишите изменение своими словами.

4. **Внеси точечное изменение** в конфиг, покажи diff «было → стало», подтверди. Не трогай другие
   секции. Если меняется общая для плагинов сущность (компания) — правь в `company-profile.md` и
   предупреди, что изменение затронет все плагины форка.

5. **Подтверди:** «Готово. `[секция]`: было `[X]` → стало `[Y]`. Остальное не тронул.»

## Пример
```
/korporativnoe-pravo:customize
Устав теперь непубличного АО, а не ООО — обнови устройство общества
```
