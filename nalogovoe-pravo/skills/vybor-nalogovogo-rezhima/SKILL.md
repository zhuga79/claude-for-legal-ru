## Критично — реформа НДС на УСН, проверь дату перед любым выводом

**С 2025 года УСН больше не означает «без НДС» автоматически.** Это ключевое структурное
изменение, которого нет в старых материалах и учебниках до 2024 года — не полагайся на
устаревшее знание. Схема (общий принцип, точные цифры — сверить на дату вопроса, они
меняются ежегодно `[проверить по первоисточнику]`):

- Налогоплательщик на УСН освобождён от НДС автоматически, пока его доход **за предыдущий
  календарный год** не превысил порог. Порог снижается по годам: 60 млн ₽ (доход за 2024 год →
  освобождение в 2025) → 20 млн ₽ (доход за 2025 год → освобождение в 2026) → далее ниже по
  объявленному графику. **Проверка не заканчивается на прошлом годе: если доход в течение
  текущего года превысит действующий порог, обязанность по НДС возникает с 1-го числа месяца,
  следующего за месяцем превышения** `[сверено 2026-08-26]` — считать нужно оба среза, не только
  входной.
- При превышении порога налогоплательщик на УСН обязан платить НДС и выбирает между:
  - **пониженными ставками без права вычета** входящего НДС — **не выбираются свободно**:
    привязаны к диапазону дохода (на 2026 год — 5% до 272,5 млн ₽, 7% от 272,5 до 490,5 млн ₽,
    границы индексируются тем же дефлятором, что и лимит УСН) `[сверено 2026-08-26]`, или
  - **базовой ставкой НДС с правом на вычет** входящего налога — доступна при любом доходе в
    пределах лимита УСН, если налогоплательщик выбрал этот вариант вместо пониженной ставки.

  Выбор между базовой и доступной пониженной ставкой зависит от доли входящего НДС в структуре
  расходов — единого правильного ответа нет, считать для конкретного бизнеса.
- **Базовая ставка НДС с 2026 года — 22%** (повышена с 20%). Это меняет расчёт не только для
  ОСНО, но и для УСН-плательщиков, выбравших базовую ставку с вычетом.
- Заявление в налоговый орган для применения пониженных ставок/освобождения не требуется —
  действует автоматически по факту дохода за предыдущий год.

**Практическое следствие для этого скилла:** сравнение «УСН дешевле, потому что там нет НДС» —
верно только для налогоплательщиков ниже порога освобождения. Для бизнеса с оборотом выше
порога сравнение УСН и ОСНО должно включать НДС по обеим системам, а не только по ОСНО.

## Системы — что проверять по каждой (лимиты и ставки — сверить на дату вопроса)

### 1. ОСНО

Применяется по умолчанию, без ограничений по обороту и численности. Налоги для ЮЛ: НДС (базовая
ставка / 10% / 0%), налог на прибыль **25%** (с 01.01.2025, ФЗ от 12.07.2024 № 176-ФЗ; ранее
20% — не используй устаревшую ставку; расщепление на федеральную и региональную часть)
`[сверено 2026-08-26]`, налог на имущество, страховые взносы, НДФЛ как налоговый агент. Для ИП
на ОСНО — НДС + НДФЛ вместо налога на прибыль.

**Плюс:** нет ограничений; полный вычет НДС с покупок — важно для B2B.
**Минус:** самая сложная отчётность; при доходе ниже порога освобождения УСН обгонит по
налоговой нагрузке.

### 2. УСН «доходы» и «доходы минус расходы»

**Лимиты доходов и остаточной стоимости ОС индексируются ежегодно коэффициентом-дефлятором.**
На 2026 год (коэффициент 1,090, приказ Минэкономразвития № 734) `[сверено 2026-08-26 —
переверить на дату вопроса, если сессия давняя]`: предельный доход для сохранения права на УСН —
**490,5 млн ₽** (база 450 млн ₽ × 1,090), остаточная стоимость основных средств — **218 млн ₽**
(база 200 млн ₽ × 1,090), численность — до 130 человек. **Модель «повышенная ставка при ¾
лимита, потеря права по кварталам» из редакции до 2025 года больше не действует** — с 2025 года
структура УСН перестроена вместе с реформой НДС: единые ставки 6%/15% без промежуточной
повышенной ступени по самому УСН-налогу (повышенная ступень осталась только в ставках НДС, см.
ниже), утрата права на УСН — при превышении 490,5 млн ₽ с начала того квартала, в котором
произошло превышение. Перечень расходов для «доходы минус расходы» с 2026 года не является
полностью закрытым в прежнем виде — часть расходов определяется по правилам главы 25 НК
`[сверено 2026-08-26, детали состава — проверить отдельно перед использованием]`.

- **Доходы 6%:** налог уменьшается страховыми взносами (до 50% для организаций и ИП с
  работниками; до 100% для ИП без работников при уплате фиксированных взносов). Не учитывает
  расходы — не подходит для бизнеса с высокой долей затрат.
- **Доходы минус расходы 15% (закрытый перечень расходов ст. 346.16 НК):** минимальный налог
  1% от доходов, если расчётный 15% от прибыли меньше.

**Отдельно от лимита на применение УСН — порог обязательной уплаты НДС** (см. раздел выше). Оба
порога проверяются самостоятельно, один не подменяет другой.

### 3. АУСН

Пилотный режим для очень малого бизнеса (регион регистрации — из пилотного перечня, проверить
актуальный список на дату вопроса `[проверить]`; численность — до 5 человек). Лимит дохода —
**60 млн ₽/год**, реформой 2025–2026 не затронут — экспериментальный закон (ФЗ от 25.02.2022
№ 17-ФЗ) прямо запрещает менять этот лимит до конца эксперимента `[сверено 2026-08-26]`.
Особенность — стандартный тариф страховых взносов за работников нулевой (заложен в ставку
налога), но **взнос на страхование от несчастных случаев на производстве (травматизм) уплачивается
отдельно фиксированной суммой** — формулировка «взносы отдельно не уплачиваются» неточна
`[сверено 2026-08-26]`. Декларации не подаются (расчёт по банковским выпискам). Подходит для
микробизнеса, где важна минимизация отчётности, а не оптимизация ставки.

### 4. ПСН (только для ИП)

Патент по перечню видов деятельности (ст. 346.43 НК). Лимит дохода для сохранения права на патент
(пп. 1 п. 6 ст. 346.45 НК) снижается по годам той же реформой, что и порог НДС на УСН —
**60 млн ₽ (до 2025 включительно) → 20 млн ₽ (с 2026 года) → 15 млн ₽ (с 2027 года, по доходу за
2026 год)** `[сверено 2026-08-26 по вторичным источникам — при работе после длительного перерыва
свериться напрямую по тексту статьи]`. Считается по доходу от реализации за текущий и
предшествующий год, утрата права — с начала налогового периода, на который выдан патент.
Стоимость патента — фиксированная сумма, устанавливается региональным законом от потенциально
возможного дохода, не зависит от фактической выручки в пределах лимита. Подходит, когда
предсказуемость платежа важнее точной оптимизации.

### 5. ЕСХН

Для сельхозпроизводителей с долей сельхозвыручки выше установленного порога (проверить точный
процент по первоисточнику). Налог — процент от прибыли, ниже стандартной ставки налога на
прибыль.

### 6. НПД (самозанятые)

Для физлиц и ИП без работников, с лимитом годового дохода **2,4 млн ₽** (считается нарастающим
итогом с 1 января по 31 декабря, без помесячного ограничения) — п. 8 ч. 2 ст. 4 ФЗ от 27.11.2018
№ 422-ФЗ, фиксированная сумма, дефлятором не индексируется, на 2026 год без изменений
`[сверено 2026-08-26]`. Пониженные ставки при работе с физлицами и с юрлицами/ИП соответственно.
**Запрет НПД действует только на доходы от конкретного бывшего работодателя в течение двух лет
после увольнения (п. 8 ч. 2 ст. 6 ФЗ-422) — это не лишает лицо права применять НПД к доходам от
других заказчиков** `[сверено 2026-08-26]`; отдельно — перечень видов деятельности, исключённых
из НПД, закрытый, не расширять по аналогии. Минус — отсутствие страховых взносов означает
отсутствие формирования пенсионных прав по общим правилам.

### Шаг 2. Отфильтруй применимые системы

| Система | Применима? | Основание |
|---------|-----------|-----------|
| ОСНО | да, всегда | по умолчанию |
| УСН доходы 6% | [да/нет] | лимиты доходов/численности/ОС на текущий год |
| УСН доходы-расходы 15% | [да/нет] | те же лимиты |
| АУСН | [да/нет] | регион из пилотного перечня + лимиты |
| ПСН | [да/нет] | только ИП + ОКВЭД из перечня |
| ЕСХН | [да/нет] | доля сельхозвыручки выше порога |
| НПД | [да/нет] | только физлицо/ИП без работников + лимит дохода |

### Шаг 3. Посчитай налоговую нагрузку по каждой применимой системе

Для каждой — сумма всех налогов (НДС **с учётом порога освобождения и выбора ставки при
превышении**, налог на прибыль/УСН, имущественный, страховые взносы, НДФЛ работников),
сложность учёта, влияние на денежный поток.

**Не пропускай проверку порога НДС для УСН-вариантов** — именно здесь чаще всего расходится
устаревшее представление «на УСН НДС нет» с текущим правом.

### Шаг 4. Проверь специфику

- **B2B-контрагенты, которым нужен вычет НДС:** ОСНО или УСН с базовой ставкой НДС и правом
  вычета — часто выгоднее УСН с пониженной ставкой без вычета, если доля входящего НДС высока.
- **Малая розница/услуги для физлиц:** УСН доходы-расходы или ПСН для ИП — предсказуемость важнее
  точной оптимизации.
- **Фрилансер/самозанятый:** НПД, пока доход не приближается к лимиту — тогда переход на ИП/УСН.
- **IT-компания:** проверь применимость льгот по аккредитации Минцифры (пониженная ставка налога
  на прибыль, пониженные страховые взносы, льгота по НДС для реализации прав на ПО из реестра —
  `[проверить актуальные условия льгот, они пересматривались]`) — часто ОСНО с льготами выгоднее
  УСН для B2B-модели.
- **Сельхозпроизводитель:** ЕСХН обычно оптимален при выполнении порога доли выручки.

## Чего не делает

- Не подаёт заявление о переходе в ФНС — это сам бизнес/аутсорс.
- Не делает ретроспективный пересчёт при вынужденном переходе — это бухгалтерия.
- Не оценивает налоговые последствия конкретной сделки — используй профильный skill плагина по
  предмету сделки, а не этот.
