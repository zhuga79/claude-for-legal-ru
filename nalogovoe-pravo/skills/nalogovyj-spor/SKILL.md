# Налоговый спор в арбитражном суде

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nalogovoe-pravo/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nalogovoe-pravo:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — трёхмесячный срок на иск пиши в реестр
дела немедленно, не отложенно.

Смежные скиллы: `/nalogovoe-pravo:nalogovaya-proverka` — возражения на акт (стадия до решения),
`/nalogovoe-pravo:dosudebnoe-obzhalovanie` — жалоба в УФНС (обязательна перед этой стадией),
`sudebnyj-process` — общие процессуальные вопросы АПК за пределами налоговой специфики.

## Pre-flight

- Решение УФНС получено, копия в материалах дела.
- **Срок 3 месяца на иск считать с даты получения решения УФНС (ст. 198 АПК) — не пропустить.**
  Если УФНС не вынесло решение по жалобе в установленный срок — трёхмесячный срок на иск считать
  с даты истечения срока на рассмотрение жалобы, а не ждать фактического решения
  `[сверено 2026-08-26]`.
- Платёжное поручение по госпошлине готово.
- Материалы досудебной стадии собраны полностью: акт, возражения, решение территориального
  органа ФНС, жалоба, решение УФНС.
- Решён вопрос о привлечении outside-адвоката ФПА для дел с материальной суммой.

## Госпошлина (ст. 333.21 НК)

Требование о признании недействительным решения (действия/бездействия) налогового органа —
**неимущественное, с фиксированной пошлиной** `[сверено 2026-08-26]`: свободного выбора между
имущественной и неимущественной квалификацией «как выгоднее» нет, категория определяется
характером требования, а не усмотрением заявителя.

| Категория иска | Размер |
|---|---|
| Оспаривание решения/действия налогового органа (неимущественное) | фиксированная сумма для организаций, меньше для физлиц `[проверить актуальный размер]` |
| Заявление об обеспечительных мерах | отдельная фиксированная сумма |

## Workflow

### Шаг 1. Решение — иск / согласие с доначислением / уплата

| Опция | За | Против |
|---|---|---|
| Уплатить и согласиться | дело закрыто, возможны смягчающие при будущих проверках | потеря суммы, прецедент против себя |
| Иск в АС | шанс на отмену/снижение | издержки (пошлина + outside-адвокат), длительность, неопределённый исход |
| Иск + частичная уплата | снижает риски (пеня, уголовный) | издержки выше |

### Шаг 2. Подготовка позиции

**Анализ решения УФНС:** какие выводы сделаны, какие аргументы налогоплательщика приняты/отклонены,
появились ли новые факты, которые УФНС не рассматривал.

**Процедурные аргументы** (часто работают эффективнее материальных, если применимы):
- нарушен срок проведения проверки;
- документы не были предоставлены налогоплательщику для ознакомления (п. 3.1 ст. 100 НК);
- заседание по рассмотрению акта проведено без надлежащего извещения (п. 2 ст. 101 НК);
- иное нарушение процедуры, могущее быть самостоятельным основанием отмены (п. 14 ст. 101 НК)
  `[проверить формулировки по первоисточнику]`.

**Материальные аргументы:** по каждому эпизоду — сильнейший аргумент и подтверждающие
доказательства.

**Доказательственная база:** новые доказательства, не представленные или не существовавшие на
досудебной стадии; свидетели; экспертизы по техническим/финансовым вопросам; заключения
специалистов.

**Судебная практика:** благоприятная (позиции Пленума ВС/ВАС, определения ВС, недавние дела по
аналогичным вопросам — искать через `mcp__ru-kad__search_cases`, не подставлять номера дел по
памяти без проверки) и неблагоприятная (предвидеть и подготовить контраргументы).

### Шаг 4. Обеспечительные меры (ст. 91 АПК)

**Критично для налоговых споров** — без них территориальный орган ФНС может продолжить взыскание
(приостановление операций, обращение на имущество) вне зависимости от рассмотрения дела судом.

```markdown
# В Арбитражный суд [...] по делу № [будет присвоен]
# ХОДАТАЙСТВО о принятии обеспечительных мер

В производстве суда находится заявление о признании недействительным решения [реквизиты].
В целях обеспечения исполнения судебного акта и предотвращения значительного ущерба заявителю
просим принять обеспечительные меры.

## Обоснование
1. Без обеспечительных мер орган вправе приостановить операции по счетам (ст. 76 НК), обратить
   взыскание на имущество (ст. 47 НК).
2. Сумма доначисления [сумма] существенна для заявителя [привести данные о финансовом положении].
3. Заявитель уплатил госпошлину и активно отстаивает позицию — баланс интересов не нарушается.
4. Налоговый орган не лишается права взыскания при подтверждении законности решения после
   вступления в силу судебного акта.

## Испрашиваемые меры
1. Запретить [орган] совершать действия по взысканию доначисленных сумм до вступления решения
   суда по делу в законную силу.
2. Приостановить действие оспариваемого решения в указанной части.

[Подпись, дата]
```

### Шаг 5. Подготовка к заседаниям

Анализ отзыва ФНС на иск, подготовка возражений на отзыв, дополнительные доказательства,
идентификация свидетелей/экспертов, координация с outside-адвокатом. В заседании — очерёдность
выступлений сторон, допрос свидетелей при наличии, исследование документов, прения.

**Инстанции:** первая инстанция → апелляция (**арбитражный апелляционный суд**, не суд округа) в
установленный срок после решения → кассация (**арбитражный суд округа**) в установленный срок
после апелляции → Верховный Суд как экстраординарная инстанция `[сверено 2026-08-26: апелляция и
кассация ранее были перепутаны местами]` `[проверить актуальные процессуальные сроки по АПК]`.

## Стратегические соображения

**Практика по налоговым спорам:** доля выигрышей налогоплательщиков варьируется по регионам и
категориям споров и не гарантирована; процедурные аргументы часто работают эффективнее
материальных при их наличии; качество документального обоснования — решающий фактор
`[статистику по проценту выигрышей — если нужна в выводе — сверять по актуальным источникам
на дату вопроса, устаревшие цифры быстро теряют силу]`.

**Привлечение outside-адвоката:** сумма выше порога материальности из профиля; сложная правовая
позиция; уголовный риск; высокая публичная значимость дела.

**Альтернативы формальному settlement:** уплата доначисленного сама по себе спор не прекращает и
не лишает права добиваться признания решения недействительным с последующим возвратом или зачётом
`[сверено 2026-08-26]` — прекращение спора после частичной уплаты возможно только через отдельный
процессуальный шаг (отказ от части требований по своей инициативе), а не автоматически; уплата с
продолжением апелляции по остальным периодам; внесудебные переговоры через outside-адвоката.

## Чего не делает

- Не представляет интересы в суде — нужен живой представитель.
- Не ведёт переговоры об урегулировании — это outside-адвокат.
- Не заменяет полную консультацию по стратегии судебного процесса для материальных дел.
