# Трансфертное ценообразование

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nalogovoe-pravo/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nalogovoe-pravo:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — срок подачи уведомления (20 мая года,
следующего за отчётным) пиши в реестр дела как повторяющийся годовой срок.

## Область — сложная, для материальных сделок привлекать консультанта

Раздел V.1 НК действует с 2012 года и регулярно пересматривается. Этот скилл помогает
структурировать анализ, но для материальных сделок (см. порог в профиле, ориентир — свыше
100 млн ₽) — привлекать outside-консультанта с опытом трансфертного ценообразования, а не
полагаться на вывод модели как на итоговую документацию.

## Ключевые понятия (пороги ст. 105.14 НК сверены 2026-08-26)

### Взаимозависимость (ст. 105.1 НК)

Возникает при: прямом или косвенном участии свыше 25% (доля косвенного участия считается по
правилам ст. 105.1 НК — произведение долей по цепочке, а не по голосам или по активам)
`[сверено 2026-08-26]`; праве одного лица назначать более 50% органов управления другого;
семейных отношениях между физлицами; зависимости через цепочку лиц с участием каждого звена
свыше 50%; ином доказанном фактическом контроле.

### Контролируемость сделки (ст. 105.14 НК)

Пороги по сумме доходов за календарный год `[сверено 2026-08-26, перепроверено независимым
провайдером]`:

- **120 млн ₽** (п. 1 ст. 105.14 НК) — сделки с лицом из юрисдикции, включённой в перечень
  офшорных зон; совокупность сделок через посредника-резидента РФ, не выполняющего в цепочке
  никаких функций кроме организационных (сумма считается по цепочке); сделки в области внешней
  торговли биржевыми товарами (нефть, чёрные и цветные металлы, минеральные удобрения,
  драгоценные металлы и камни);
- **1 млрд ₽** (п. 2–3 ст. 105.14 НК) — внутрироссийские сделки между взаимозависимыми лицами
  при наличии особых обстоятельств (разные налоговые ставки сторон, применение спецрежима одной
  из сторон, отраслевая льгота — например IT-аккредитация, резидентство ОЭЗ, статус плательщика
  НДПИ по адвалорной ставке в отношении добытого по этой ставке ископаемого, и аналогичные случаи
  из п. 2 ст. 105.14 НК); тот же порог 1 млрд ₽, а не отсутствие порога, применяется и к НДПИ-случаю;
- **обычные трансграничные сделки** между взаимозависимыми лицами также подпадают под контроль —
  контролируемость не ограничена только офшорами/посредниками/биржевыми товарами, порог для них —
  общий 1 млрд ₽ по п. 2–3, если применимы обстоятельства п. 2.

### Методы определения рыночной цены (ст. 105.7–105.13 НК)

| Метод | Когда применяется |
|---|---|
| Сопоставимых рыночных цен (метод по умолчанию, приоритетный) | есть сопоставимые сделки с независимыми лицами |
| Цены последующей реализации | для торговых посредников |
| «Издержки плюс» | для производителей и поставщиков услуг |
| Сопоставимой рентабельности | наиболее часто применяемый на практике, когда других данных нет |
| Распределения прибыли | сделки с уникальными нематериальными активами или сложной цепочкой создания стоимости |

Метод сопоставимых рыночных цен имеет приоритет при наличии сопоставимых данных. Строгой
последовательной иерархии остальных четырёх методов нет — выбор среди них делается по
обстоятельствам конкретной сделки, сочетание нескольких методов в отдельных случаях допускается
`[сверено 2026-08-26]`.

### Уведомление о контролируемых сделках (ст. 105.16 НК)

Срок подачи — до 20 мая года, следующего за отчётным. Содержание — перечень контролируемых
сделок, сгруппированных по контрагентам, с применённым методом, в электронном формате по
установленной схеме ФНС. Штраф по ст. 129.4 НК за непредставление в срок либо за представление
уведомления с недостоверными сведениями — фиксированный, **100 000 ₽** `[сверено 2026-08-26]`;
не зависит от числа сделок в уведомлении. Отдельно возможен штраф по КоАП на должностных лиц
организации `[проверить актуальные размеры]`. Плюс риск доначисления при выявлении занижения цены
проверкой.

### Документация по требованию ФНС (ст. 105.15 НК)

Предоставляется по требованию, а не автоматически. Срок предоставления — 30 дней с получения
требования `[сверено 2026-08-26]`. Содержание: обоснование выбора метода, обоснование сопоставимости
отобранных сделок, функциональный анализ сторон, расчёт рыночного диапазона. Готовить документацию
заранее для материальных сделок — реконструкция постфактум сложнее и менее убедительна.

## Workflow

### Шаг 1. Установи взаимозависимость

```markdown
## Стороны сделки
Сторона А: [наименование + ИНН] · Сторона Б: [наименование + ИНН]

## Анализ по ст. 105.1 НК
| Основание | Применимо? |
|---|---|
| Прямое участие свыше 25% | [да/нет] |
| Косвенное участие свыше 25% (через цепочку) | [да/нет] |
| Назначение свыше 50% органов управления | [да/нет] |
| Семейные отношения | [да/нет] |
| Иной фактический контроль | [да/нет] |

Вывод: стороны [взаимозависимы / не взаимозависимы]
```

### Шаг 2. Установи контролируемость (если взаимозависимы)

```markdown
## Анализ по порогам ст. 105.14 НК
- Суммарный доход по сделкам с контрагентом за год: [сумма]
- Применяет ли любая из сторон спецрежим или льготу: [да/нет]
- Контрагент из юрисдикции с льготным режимом: [да/нет]
- Сделка с биржевым товаром международной торговли: [да/нет]

Вывод: сделки [контролируемые / неконтролируемые] для целей раздела V.1
```

### Шаг 3. Определи метод (если контролируемые)

Функциональный анализ: функции сторон (производство/распределение/маркетинг/НИОКР/финансовое
сопровождение), используемые активы, принимаемые риски. Поиск сопоставимых сделок — внутренних
(с независимыми контрагентами по тому же предмету) и внешних (базы данных, публичная информация).
Выбор метода по таблице выше с обоснованием, почему приоритетные методы неприменимы, если выбран
не метод сопоставимых рыночных цен.

### Шаг 4. Собери данные для документации

Описание сделки (стороны, предмет, объём, цена, условия); функциональный анализ по каждой стороне
с итоговой характеристикой (полнофункциональный производитель / контрактный производитель /
дистрибьютор с ограниченными рисками и т.п.); анализ сопоставимых — параметры отбора, применённые
фильтры, финальная выборка, для метода сопоставимой рентабельности — расчёт межквартильного
диапазона; применение метода — расчёт рыночного диапазона, сравнение с фактической ценой,
итоговый вывод о соответствии.

### Шаг 5. Подготовь уведомление

Электронный формат по актуальной схеме ФНС: реквизиты налогоплательщика, перечень контролируемых
сделок (даты начала и окончания, контрагент, предмет по классификатору, сумма, применённый
метод).

### Шаг 6. При получении требования о документации

Зафиксировать дату получения (начало срока), оценить готовность документации, при необходимости —
ходатайствовать о продлении, при существенном объёме — привлечь outside-консультанта. Пакет:
сопроводительное письмо с описанием, полный отчёт по трансфертному ценообразованию, подтверждающие
документы, расчёты в рабочем виде.

## Стратегические соображения

**Готовить документацию заранее** для материальных сделок — снижает риск доначисления,
демонстрирует добросовестность, проще, чем реконструкция постфактум.

**Привлечение outside-консультанта** — для материальных сделок (см. порог в профиле): специализированные
консалтинговые компании с опытом трансфертного ценообразования в РФ.

**Зоны повышенного риска на практике:** роялти и лицензионные платежи в низконалоговые юрисдикции;
управленческие и внутригрупповые сервисные сборы — требуется подтверждение реальности услуг;
внутригрупповые займы — сравнение со ставками независимых банков; продажа связанному дистрибьютору
с заниженной маржой — часто переквалифицируется; продажа нематериальных активов связанной стороне
— повышенное внимание, требует независимой оценки.

## Чего не делает

- Не подаёт уведомление в ФНС — это бухгалтерия/IT-служба.
- Не готовит полное исследование трансфертного ценообразования — это outside-консультант.
- Не разбирает уже возникший спор по трансфертному ценообразованию — это
  `/nalogovoe-pravo:nalogovaya-proverka`.
