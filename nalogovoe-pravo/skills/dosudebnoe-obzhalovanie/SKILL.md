# Досудебное обжалование решения налогового органа

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/nalogovoe-pravo/CLAUDE.md`. Файла нет или
`[ЗАПОЛНИТЬ]` — стоп, направь на `/nalogovoe-pravo:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — все сроки этой стадии пиши в реестр дела.

## Обязательность стадии — не пропускать

**Без досудебного обжалования в арбитражный суд обратиться нельзя (ст. 138 НК).** Это специальный
режим, отличающий налоговые споры от большинства других категорий — иск в АС, поданный минуя
досудебную стадию, суд оставит без рассмотрения.

## Pre-flight

### Какое решение обжалуется

| Тип решения | Применимая жалоба |
|---|---|
| По результатам проверки (привлечение / отказ в привлечении к ответственности) | апелляционная — если до вступления в силу; обычная — если после |
| О взыскании налога / приостановлении операций (ст. 46–47, 76 НК) | жалоба |
| Об отказе в возмещении НДС | жалоба |
| Действия/бездействие должностных лиц ФНС | жалоба |

### Сроки — критично

| Жалоба | Срок |
|---|---|
| Апелляционная | 1 месяц с получения решения, **до** вступления решения в силу |
| Обычная | 1 год с момента вынесения решения |
| В ФНС России на решение УФНС | 3 месяца с вынесения решения УФНС |

Начало срока — со дня получения (лично, по почте) или доставки в личный кабинет налогоплательщика,
для обычной жалобы на акты/действия/бездействие (не на решение по проверке) — со дня, когда лицо
узнало или должно было узнать о нарушении своих прав `[сверено 2026-08-26]`. Пропуск срока — жалоба
возвращается без рассмотрения.

**Восстановление — только для обычной жалобы.** По п. 2 ст. 139 НК `[сверено 2026-08-26]`:
письменное ходатайство о восстановлении, поданное вместе с жалобой в вышестоящий налоговый орган,
при уважительной причине пропуска (например, болезнь, обстоятельства непреодолимой силы) —
перечень уважительных причин в норме не закрыт, оценивает налоговый орган. **Месячный срок
апелляционной жалобы (ст. 139.1 НК) восстановлению не подлежит** — при его пропуске остаётся
только подать обычную жалобу после вступления решения в силу `[сверено 2026-08-26]`.

### Куда подавать

**Апелляционная и обычная жалобы подаются только через орган, вынесший обжалуемый акт (решение,
действие или бездействие) — он перенаправляет жалобу в УФНС в установленный срок.** Прямая подача
в УФНС, минуя орган, чей акт обжалуется, не соответствует ст. 139, 139.1 НК `[сверено 2026-08-26]`.
Жалоба в ФНС России на решение УФНС — аналогично, через вынесший её орган. Личный кабинет
налогоплательщика — оптимальный канал: быстро, с подтверждением получения.

### Госпошлина

За досудебную жалобу отсутствует (в отличие от арбитражного суда) — это делает досудебную стадию
дешёвым способом попробовать оспорить решение даже при невысоких шансах.

## Workflow

### Шаг 1. Определи содержание для обжалования

Эпизоды доначисления — те же, что в акте, с учётом изменений после рассмотрения возражений; сумма
по каждому эпизоду, пени, штрафы.

### Шаг 2. Переоцени аргументы после решения

Из каждого аргумента возражений: принят полностью (эпизода больше нет в решении) → не оспаривать;
принят частично → не оспаривать принятую часть; отклонён → готовить для жалобы, с учётом новых
аргументов или документов, появившихся после акта.

### Шаг 3. Собери жалобу

```markdown
# АПЕЛЛЯЦИОННАЯ ЖАЛОБА
на решение [полное название и реквизиты]

В: Управление ФНС России по [субъекту РФ]
Через: [территориальный орган ФНС]

Налогоплательщик: [полное наименование, ИНН, КПП, ОГРН, юр. и факт. адрес, контакты]

Обжалуемое решение: [орган, реквизиты, дата получения]

## Суть обжалования
Решением [реквизиты] налогоплательщик привлечён к ответственности; доначислено налогов
[сумма] ₽, пеней [сумма] ₽, штрафов [сумма] ₽. С решением налогоплательщик не согласен по
следующим основаниям.

## По эпизоду № 1: [название]
### Содержание оспариваемого
[цитата из решения + сумма]
### Позиция налогоплательщика
[развёрнутое обоснование, дополняющее возражения]
### Правовые аргументы
1. [главный аргумент] — норма НК, письмо Минфина/ФНС, позиция Пленума ВС или определение ВС
2. [второй аргумент]
3. [процедурный аргумент, если есть]
### Просим
Отменить решение в части эпизода № 1, исключить доначисление налога [X] ₽, пени [Y] ₽,
штраф [Z] ₽.

## По эпизоду № 2–N
[то же]

## Процедурные нарушения (если выявлены)
Срок проверки превышен; документы не предоставлены для ознакомления; заседание проведено без
уведомления; решение содержит неустранимые противоречия с актом. По п. 14 ст. 101 НК
несоблюдение установленных требований может быть основанием для отмены решения
`[проверить формулировку по первоисточнику]`.

## Просительная часть
На основании ст. 101.2, 137–140 НК РФ прошу:
1. Отменить решение [реквизиты] в части [перечень эпизодов] / полностью
2. Вынести новое решение об отказе в привлечении к ответственности в указанной части
3. Альтернативно — снизить штрафы с учётом смягчающих обстоятельств (ст. 114 НК): [перечислить]

## Приложения
[копия решения, подтверждающие документы, расчёты, доверенность при необходимости]

[Подпись руководителя или уполномоченного представителя, должность, дата]
```

### Шаг 4. Подача и учёт

Способы: личный кабинет налогоплательщика (оптимально), лично в канцелярию со штампом, почтой с
описью, через представителя по доверенности. После подачи: жалоба направляется в УФНС в
установленный срок, УФНС рассматривает в течение установленного срока с возможным продлением при
необходимости запросить документы `[проверить точные сроки по первоисточнику]`.

### Шаг 5. Решение УФНС — дальнейшие шаги

**Положительное** (отмена или существенное снижение) — дело закрывается на досудебной стадии,
возврат излишне взысканного в установленном порядке.

**Отрицательное или частично отрицательное:**

- **Жалоба в ФНС России** — необязательная стадия, срок 3 месяца с вынесения решения УФНС.
  **Важно:** подача в ФНС России не приостанавливает трёхмесячный срок на иск в АС — оба срока
  текут независимо. Рекомендация — подавать иск в АС сразу после неблагоприятного решения УФНС,
  не дожидаясь ФНС России.
- **Иск в арбитражный суд** — обязательная следующая стадия, срок 3 месяца со дня получения
  решения УФНС (ст. 198 АПК). См. `/nalogovoe-pravo:nalogovyj-spor`.

## Стратегические соображения

**Выборочно или комплексно.** Выборочно — 2–3 сильнейших эпизода, проще для рассмотрения. Комплексно
— все эпизоды, риск выглядеть неорганизованно, но полнее база для последующего суда. Рекомендация:
комплексно в письменной жалобе, устно на заседании — фокус на сильнейших пунктах.

**Возможности компромисса:** полная отмена; частичное снижение доначисления; снижение штрафов по
смягчающим обстоятельствам (ст. 112, п. 3 ст. 114 НК); отсрочка или рассрочка уплаты (ст. 61–64 НК).
Договорного снижения законно исчисленного налога по соглашению с налоговым органом не существует
`[сверено 2026-08-26]` — формального settlement в американском стиле нет.

## Чего не делает

- Не подаёт жалобу — нужна подпись.
- Не заменяет outside-адвоката ФПА для материальных дел.
- Не ведёт стадию арбитражного суда — это `/nalogovoe-pravo:nalogovyj-spor`.
