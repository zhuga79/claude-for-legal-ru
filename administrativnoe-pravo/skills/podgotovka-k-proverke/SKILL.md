# Подготовка к проверке регулятора

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/administrativnoe-pravo/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/administrativnoe-pravo:cold-start-interview`.

Если включён режим `vedenie-del` и известна дата начала проверки — зафиксируй её в реестре дела.

## Разграничение стадий — важно

**Это скилл для стадии ДО проверки.** Сама проверка регулятора (контрольно-надзорное мероприятие
по 248-ФЗ) — это ещё не производство по делу об административном правонарушении. Дело по КоАП
может открыться по итогам проверки, а может не открыться вовсе (проверка без нарушений,
предписание без протокола). Во время самой проверки — `/administrativnoe-pravo:zaschita-pri-proverke`.
Если по итогам проверки составлен протокол — `/administrativnoe-pravo:otvet-na-protokol-koap`.

## Workflow

### Шаг 1. Определи параметры проверки

```markdown
## Параметры проверки

- **Регулятор:** [ФНС / РКН / ФАС / Роспотребнадзор / Ростехнадзор / Росприроднадзор / МЧС / иной]
- **Тип:** [плановая / внеплановая / документарная / выездная / профилактическое мероприятие]
- **Решение о проведении № [N] от [ДД.ММ.ГГГГ]:** [реквизиты]
- **Проверяемый период:** [с — по]
- **Предмет проверки:** [конкретно, например — соблюдение 152-ФЗ]
- **Срок проверки:** [N дней]
- **Состав проверяющих:** [список — сверить через реестр регулятора при возможности]
- **Применим ли мораторий для МСП:** [да/нет]
```

**Мораторий на плановые проверки (ПП РФ № 336, продлён до 2030 года постановлениями № 372 и
№ 1955) `[сверено 2026-08-27]`** — закрывает плановые проверки для субъектов МСП вне объектов
высокого и чрезвычайно высокого риска. **Не распространяется на внеплановые проверки** и не
распространяется на налоговый, валютный и таможенный контроль. Если проверка внеплановая — довод
о моратории не работает, даже если субъект в реестре МСП.

### Шаг 2. Определи вероятные фокус-области регулятора

У каждого регулятора — типовой чек-лист проверки (в основном публичный):

| Регулятор | Типичный фокус |
|---|---|
| ФНС | Отдельный контур — см. `nalogovoe-pravo` (акт налоговой проверки — иная процедура, НК, не КоАП) |
| РКН | Уведомление оператора ПДн, политика обработки, ПВД, ОВПД для высокорисковой обработки, локализация (ст. 18 ч. 5 ФЗ-152), трансграничная передача |
| ФАС | Антимонопольные документы, сделки экономической концентрации выше порогов, реклама (38-ФЗ), госзакупки (44/223-ФЗ) при участии |
| Роспотребнадзор | СанПиН, ПДн потребителей, документация предприятия торговли/общепита |
| Ростехнадзор | Лицензии на опасные производства, журналы техбезопасности, регистрация опасных производственных объектов |
| Росприроднадзор | Экологические разрешения, платежи за негативное воздействие, учёт выбросов/отходов |
| МЧС | Пожарная декларация, противопожарные мероприятия, журналы тренировок, сертификация оборудования |
| ГИТ (Роструд) | Отдельный контур — `trudovoe-pravo` |

### Шаг 3. Self-audit по предмету проверки

```markdown
## Чек-лист самопроверки

### Критично (несоответствие → высокий риск нарушения)
- [ ] [конкретное требование по типу регулятора]
- [ ] [ещё требование]

### Важно
- [ ] [...]

### Хорошая практика
- [ ] [...]
```

### Шаг 4. Документация в порядок

```markdown
## Готовность документов

### Внутренние документы
- [ ] ЛНА, регулирующие деятельность, — актуальная редакция
- [ ] Журналы/акты внутреннего контроля — заполнены
- [ ] Лицензии/сертификаты — действующие, копии готовы
- [ ] Отчётность за предыдущие периоды — доступна

### Переписка
- [ ] Письма к/от регулятора — хронологически систематизированы
- [ ] Запросы разъяснений и полученные ответы
- [ ] Ранее выданные предписания — статус исполнения

### Обучение персонала
- [ ] Журналы обучения сотрудников
- [ ] Листы ознакомления с ЛНА
- [ ] Сертификаты профессионального обучения (если применимо)

### Операционные данные
- [ ] Отчётность за проверяемый период
- [ ] Учётные регистры
- [ ] Договоры с контрагентами, относящиеся к предмету проверки
```

### Шаг 5. Инструктаж команды

```markdown
## Подготовка персонала

### Ответственные за предмет проверки
- [ФИО, должность] — основной контакт
- [ФИО, должность] — резервный

### Темы инструктажа
- [ ] Предмет и границы проверки
- [ ] Права и обязанности при проверке (см. `/administrativnoe-pravo:zaschita-pri-proverke`)
- [ ] Правила взаимодействия с проверяющими: не давать объяснений без ответственного/outside-адвоката,
      не подписывать акты без проверки, документировать все запросы
- [ ] Порядок эскалации вопросов
- [ ] Контакты outside-адвоката ФПА готовы
```

### Шаг 6. Готовность outside-адвоката

```markdown
## Внешнее сопровождение

- **Привлечён до начала проверки?** [да/нет — рекомендуется для материальных дел]
- **Специализация под конкретного регулятора:** [ФИО, контакты]
- **Оформление привилегии:** документы готовятся под адвокатской тайной, если применимо
- **Канал коммуникации:** маршрутизация материальных сообщений через outside-адвоката
```

### Шаг 7. Устранение выявленных нарушений

```markdown
## Дособлюдение перед проверкой

### Критичные нарушения (устранить до проверки)
| Нарушение | Устранение | Ответственный | Срок | Статус |
|---|---|---|---|---|
| [...] | [...] | [...] | [ДД.ММ.ГГГГ] | [...] |

### Неустранимые к сроку — фиксировать
[перечень + стратегия документирования]

### Смягчение, если устранить полностью нельзя
- Добровольное раскрытие (иногда снижает вероятный штраф)
- План устранения с фиксацией прогресса
- Консультация с outside-адвокатом о целесообразности раскрытия
```

### Шаг 8. День проверки — финальная готовность

```markdown
## День проверки

- [ ] На входе — проверка личности проверяющих (удостоверения + решение о проверке)
- [ ] Помещение для проверяющих готово
- [ ] Назначен сопровождающий/связной
- [ ] Порядок передачи документов определён
- [ ] Ответственный за комплаенс и outside-адвокат на связи
- [ ] Все сотрудники проинструктированы
- [ ] Порядок review актов перед подписанием — понятен всем
```

## Чего не делает

- Не ведёт непосредственное взаимодействие с проверяющими — это
  `/administrativnoe-pravo:zaschita-pri-proverke`.
- Не устраняет содержательные нарушения комплаенса — это профильные подразделения.
- Не заменяет полноценное сопровождение outside-адвоката для материальных дел.

- [ ] Утверждения без сверки по первоисточнику помечены `[проверить по первоисточнику]`
