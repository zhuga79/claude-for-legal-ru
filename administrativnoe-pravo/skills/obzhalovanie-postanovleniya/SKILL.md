# Обжалование постановления по делу об административном правонарушении

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/administrativnoe-pravo/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/administrativnoe-pravo:cold-start-interview`.

Если включён режим `vedenie-del` и есть активное дело — 10-суточный срок и дальнейшие сроки этой
стадии пиши в реестр дела, не держи в памяти диалога.

## Первым делом — срок

**10 суток с момента получения постановления (ст. 30.3 КоАП).** Это самый короткий срок во всём
контуре форка — короче даже налоговых сроков. Проверь дату вручения/получения раньше содержания
постановления.

⚠ **Пропуск срока → постановление вступает в силу, штраф становится обязательным к уплате** (по
общему правилу в течение 60 дней с момента вступления в силу, ст. 32.2 ч. 1 КоАП
`[проверить актуальный срок по первоисточнику]`). Восстановление пропущенного срока возможно по
ходатайству при уважительной причине (ст. 30.3 ч. 2 КоАП), но не гарантировано — не рассчитывай
стратегию на восстановление, если есть возможность подать в срок.

## Куда подавать

| Кем вынесено постановление | Куда обжаловать |
|---|---|
| Должностным лицом органа | На выбор: вышестоящему должностному лицу этого органа либо в суд по месту рассмотрения дела |
| Коллегиальным органом | На выбор: вышестоящему органу либо в суд |
| Мировым судьёй | В районный суд по территориальности |
| Судьёй районного суда | В вышестоящий суд субъекта (или приравненный) |

Жалоба подаётся через орган/судью, вынесший постановление, — он направляет её со всеми материалами
дела по подведомственности в течение установленного срока `[проверить срок передачи материалов по
первоисточнику]`, либо непосредственно в орган/суд, правомочный её рассматривать.

**Госпошлина** — не взимается (в отличие от арбитражного и гражданского процесса). Это делает
обжалование постановления дешёвым способом попробовать оспорить исход даже при умеренных шансах.

## Workflow

### Шаг 1. Разбери постановление

```markdown
## Постановление — анализ

- **№ дела:** [N] · **Дата вынесения:** [ДД.ММ.ГГГГ]
- **Дата получения:** [ДД.ММ.ГГГГ] ← отсюда считаем 10 суток
- **Орган / должностное лицо (либо суд):** [...]
- **Статья КоАП:** [...]
- **Назначенное наказание:** [штраф / предупреждение / дисквалификация / иное]
- **Размер штрафа:** [сумма]
```

### Шаг 2. Определи основания для обжалования

**А. По существу**
- Состав правонарушения не доказан
- Отсутствие вины
- Малозначительность (ст. 2.9) не применена, хотя основания были
- Смягчающие обстоятельства (ст. 4.2) не учтены при назначении наказания
- Срок давности (ст. 4.5) истёк к моменту вынесения постановления — см.
  `/administrativnoe-pravo:proverka-sroka-davnosti`

**Б. Процессуальные нарушения**
- Протокол составлен с нарушением обязательных требований (ст. 28.2 КоАП)
- Лицо не извещено надлежащим образом о месте и времени рассмотрения дела
- Рассмотрение дела в отсутствие лица при отсутствии доказательств извещения — нарушение права на
  защиту
- Доказательства получены с нарушением закона
- У должностного лица/органа не было полномочий рассматривать данное дело
- Процессуальные сроки нарушены органом

**В. Чрезмерность наказания**
- Назначен максимум статьи без отягчающих обстоятельств
- Смягчающие обстоятельства не отражены в постановлении
- Не рассмотрена возможность замены штрафа предупреждением по ст. 4.1.1 КоАП (для МСП, если
  применимо)

### Шаг 3. Собери жалобу

```markdown
В [вышестоящий орган / районный (городской) суд по месту рассмотрения дела]

# ЖАЛОБА
# на постановление по делу об административном правонарушении № [N] от [ДД.ММ.ГГГГ]

**Заявитель:** [ФИО / полное наименование, адрес, ИНН для ЮЛ/ИП, контакты]
**Орган/должностное лицо (или судья), вынесшие постановление:** [...]
**Дата получения постановления:** [ДД.ММ.ГГГГ]

## Существо обжалования
Постановлением от [ДД.ММ.ГГГГ] № [N] заявитель привлечён к ответственности по [статья] с
назначением [наказание]. С постановлением не согласен по следующим основаниям.

## 1. По существу — отсутствие состава/вины
[развёрнутое обоснование, ссылки на нормы, доказательства]

## 2. Процессуальные нарушения (если есть)
[конкретные нарушения со ссылкой на нормы КоАП]

## 3. Чрезмерность наказания (если применимо)
[смягчающие обстоятельства, не учтённые органом]

## 4. Срок давности (если применимо)
[расчёт]

## ПРОШУ (ст. 30.7 КоАП)
1. Отменить постановление от [ДД.ММ.ГГГГ] № [N];
2. Прекратить производство по делу в связи с [основание — отсутствие состава / истечение
   давности / иное]

ИЛИ

3. Изменить постановление в части наказания — снизить размер штрафа до [сумма] с учётом
   смягчающих обстоятельств / заменить штраф предупреждением

## Приложения
1. Копия обжалуемого постановления
2. Документы защиты
3. Иное

[Подпись, дата]
```

### Шаг 4. Подача

Каналы: через орган/судью, вынесший постановление (пересылает по подведомственности); напрямую в
вышестоящий орган/суд; через Госуслуги (для отдельных категорий дел); лично в канцелярию с
отметкой о принятии; почтой с описью вложения (сохранить подтверждение отправки — при коротком
10-суточном сроке дата отправки имеет решающее значение).

### Шаг 5. Рассмотрение и возможные исходы (ст. 30.7 КоАП)

| Исход | Что означает |
|---|---|
| Оставлено без изменения | Жалоба отклонена, постановление в силе |
| Отменено, производство прекращено | Дело закрыто, наказание не применяется |
| Отменено, дело возвращено на новое рассмотрение | Новое рассмотрение с начала |
| Изменено (например, снижен штраф) | Частичное удовлетворение |

### Шаг 6. Дальнейшее обжалование

Решение вышестоящего органа или первой судебной инстанции по общему правилу может быть обжаловано
дальше — **10 суток** с момента получения решения (та же логика ст. 30.3, применительно к решению
по жалобе). Экстраординарные инстанции (кассация/надзор) — отдельные, существенно более узкие
основания и более длинный срок `[проверить конкретные сроки и основания по первоисточнику на дату
дела]`.

## Стратегические соображения

**Выборочно или комплексно.** Для одного эпизода — обычно нет выбора, весь довод укладывается в
жалобу целиком. Если постановление охватывает несколько эпизодов/составов — приоритизировать
сильнейшие, второстепенные использовать как резерв для смягчающих.

**Механизмы снижения без формального settlement.** Формального мирового соглашения с органом КоАП
не предусматривает. Рабочие механизмы: снижение штрафа по смягчающим обстоятельствам (ст. 4.2,
4.1 ч. 3.2–3.3), замена штрафа предупреждением для МСП (ст. 4.1.1), скидка 50% при уплате
неоспариваемого штрафа в течение 20 дней (ст. 32.2 — применимость шире главы 12 КоАП, проверяй по
статье, см. `/administrativnoe-pravo:raschet-shtrafa`).

**Outside-адвокат ФПА.** Обязательно при дисквалификации; настоятельно рекомендуется при штрафе
выше порога материальности из профиля практики или при высоком репутационном риске.

## Формат вывода

```markdown
# Стратегия обжалования постановления — [дело]

## Критичная дата
- Получение постановления: [ДД.ММ.ГГГГ]
- Крайний срок подачи жалобы: [ДД.ММ.ГГГГ] (10 суток)

## Решение
- Обжаловать: [да/нет]
- Маршрут: [вышестоящее должностное лицо/орган / суд]
- Стратегия: [по существу / процессуальная / чрезмерность наказания / комбинированная]

## Сильнейшие аргументы
1. [...]
2. [...]

## Вероятность исхода
- Оптимистично (отмена + прекращение): X%
- Реалистично (снижение штрафа): Y%
- Пессимистично (без изменений): Z%

## Проект жалобы
[полный текст]

## План подачи
- Канал: [...]
- Дата подачи: [ДД.ММ.ГГГГ] (с запасом до крайнего срока)
- Подтверждение отправки — сохранить
```

## Чего не делает

- Не подаёт жалобу от имени заявителя — нужна подпись.
- Не представляет интересы в заседании — нужен живой представитель.
- Не заменяет outside-адвоката ФПА для дел с дисквалификацией или крупным штрафом.

---

Проверки перед выдачей:
- [ ] Срок отсчитан от даты получения постановления, а не от даты его вынесения
- [ ] Маршрут обжалования (кому/куда) определён верно по органу, вынесшему постановление
- [ ] Применимость скидки 50% при уплате оценена отдельно от решения обжаловать — это
      альтернативные, а не последовательные пути
- [ ] Утверждения без сверки по первоисточнику помечены `[проверить по первоисточнику]`
