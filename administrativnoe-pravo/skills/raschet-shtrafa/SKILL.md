# Расчёт штрафа по КоАП

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/administrativnoe-pravo/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/administrativnoe-pravo:cold-start-interview`.

## Workflow

### Шаг 1. Найди статью КоАП и её санкцию

Санкция статьи обычно задаёт диапазон отдельно для каждого субъекта:

```
Штраф для физлиц: от [X] до [Y] ₽
Штраф для должностных лиц: от [Z] до [W] ₽
Штраф для ЮЛ: от [V] до [U] ₽
+ Альтернативные наказания (предупреждение / арест / дисквалификация / приостановление
  деятельности — если предусмотрены статьёй)
```

### Шаг 2. Определи субъекта ответственности

```markdown
## Субъект ответственности

- **Тип:** [физлицо / должностное лицо / ИП / ЮЛ]
- **Применимая санкция:** [X–Y] ₽
```

**Должностное лицо ≠ ЮЛ.** Если правонарушение совершено организацией, могут быть привлечены
одновременно и должностное лицо (директор или иной ответственный), и само ЮЛ — это два
самостоятельных состава с разными штрафами, а не задвоение одного и того же наказания.

### Шаг 3. Примени модификаторы

#### A. Базовый расчёт
Ориентир по умолчанию — середина диапазона: (min + max) / 2.

#### B. Смягчающие обстоятельства (ст. 4.2 КоАП)
Раскаяние; добровольное сообщение о правонарушении (до его выявления регулятором); активное
содействие установлению обстоятельств; предотвращение вредных последствий; добровольное
возмещение ущерба; тяжёлые личные/семейные обстоятельства; для физлиц — беременность, малолетние
дети; иные — перечень открытый (ч. 2 ст. 4.2).

→ Сдвиг к нижней границе диапазона.

→ Возможно **ниже минимума** (ст. 4.1 ч. 3.2–3.3 КоАП): для должностных лиц/ИП/ЮЛ — не менее
**половины** минимального размера штрафа, предусмотренного статьёй, при исключительных
обстоятельствах, связанных с характером правонарушения и его последствиями.

#### C. Отягчающие обстоятельства (ст. 4.3 КоАП)
Продолжение противоправного поведения после требования прекратить; повторное совершение
однородного правонарушения; вовлечение несовершеннолетних; совершение группой лиц. Перечень
закрытый.

→ Сдвиг к верхней границе диапазона.

#### D. Замена штрафа предупреждением для МСП (ст. 4.1.1 КоАП)
Условия: субъект — МСП по реестру (или СОНКО); правонарушение выявлено в рамках государственного
контроля (надзора) или муниципального контроля; совершено впервые; нет причинённого вреда или
угрозы жизни/здоровью, окружающей среде, объектам культурного наследия, безопасности государства.
Применимо не ко всем составам — по конкретной статье перечень исключений
`[проверить по первоисточнику]`.

#### E. Малозначительность (ст. 2.9 КоАП)
При наличии оснований — устное замечание вместо наказания (0 ₽). Требует обоснования, применяется
не автоматически.

#### F. Скидка 50% при досрочной уплате (ст. 32.2 КоАП)

**Проверяй применимость по конкретной статье — не отбрасывай сходу.** Скидка действует шире, чем
принято считать по памяти:

| Основание | Условие | Категория штрафов |
|---|---|---|
| ч. 1.3 ст. 32.2 | Уплата не позднее установленного льготного срока со дня вынесения постановления | базовая норма, изначально ориентированная на широкий круг составов, не только гл. 12 |
| ч. 1.3-1, 1.3-3 ст. 32.2 (290-ФЗ, 2022) | Уплата в течение **20 дней** | штрафы организациям и ИП за нарушения, **выявленные в рамках государственного контроля (надзора) / муниципального контроля** — с перечнем исключений |

Постановление КС РФ от 18.07.2024 № 39-П дополнительно подтвердило применимость скидки независимо
от того, каким именно органом выявлено нарушение (не только «гражданским» ведомством).

**Точный перечень исключённых статей и точный льготный срок по каждой части — сверяй по
первоисточнику на дату конкретного дела**, а не полагайся на память: перечень обновлялся
несколько раз за последние годы `[проверить по первоисточнику]`.

### Шаг 4. Рассчитай сценарии

```markdown
## Анализ сценариев

### Без модификаторов
- Базовый диапазон: [min–max] ₽ · Вероятная середина: [average] ₽

### Со смягчающими (лучший реалистичный случай)
- По ст. 4.2 → к нижней границе: [min] ₽
- По ст. 4.1 ч. 3.2–3.3 → половина минимума при исключительных обстоятельствах: [min/2] ₽

### С отягчающими (худший случай)
- По ст. 4.3 → к верхней границе: [max] ₽

### Со скидкой 20 дней (если применима по статье)
- 50% от назначенной суммы: [50% от вероятной суммы] ₽

### Лучший случай — малозначительность
- По ст. 2.9 → устное замечание: 0 ₽

### МСП, первое нарушение (если применимо)
- По ст. 4.1.1 → предупреждение: 0 ₽
```

### Шаг 5. Матрица решения

```markdown
## Стратегическое решение

### Штраф незначителен (< 50 тыс. ₽)
- Стоимость защиты обычно выше суммы штрафа
- Рассмотреть уплату со скидкой (если применима по статье) без спора
- Защищаться — только при значимом репутационном эффекте

### Штраф материален (50–500 тыс. ₽)
- Защита через `/administrativnoe-pravo:otvet-na-protokol-koap` обычно оправдана
- Оценить вероятность снижения через смягчающие / процессуальные нарушения
- Outside-адвокат ФПА — по обстоятельствам

### Штраф крупный (> 500 тыс. ₽) или дисквалификация
- Outside-адвокат ФПА — обязательно
- Полная стратегия защиты + план обжалования, привлекать немедленно
```

## Иллюстративные категории (проверять по актуальной редакции на дату дела)

- **Ст. 5.27 КоАП (трудовые нарушения)** — диапазоны штрафов по частям статьи существенно
  различаются, включая повышенные для повторных и «зарплатных» составов.
- **Ст. 13.11 КоАП (152-ФЗ, персональные данные)** — базовые штрафы для ЮЛ значительно выросли за
  последние годы, для крупных операторов и утечек предусмотрены существенно повышенные, в т.ч.
  «оборотные» штрафы.
- **Ст. 14.5 КоАП (реклама)**, **ст. 15.27 КоАП (115-ФЗ, ПОД/ФТ)**, **ст. 7.30 КоАП (44-ФЗ, закупки)**
  — диапазоны и субъектный состав различаются по частям статьи.

Все конкретные суммы — `[проверить по первоисточнику на дату дела]`: они меняются законодателем
чаще, чем большинство норм гражданского права.
