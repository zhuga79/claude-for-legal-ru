# Защита при проведении проверки

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/administrativnoe-pravo/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/administrativnoe-pravo:cold-start-interview`.

## Pre-flight

- `/administrativnoe-pravo:podgotovka-k-proverke` пройдена
- Outside-адвокат ФПА привлечён или на связи
- Назначен сопровождающий/связной
- Команда проинструктирована

## Разграничение стадий — важно

Это стадия ВО ВРЕМЯ контрольно-надзорного мероприятия по 248-ФЗ. Дело об административном
правонарушении по КоАП, если оно возникнет, — отдельная последующая процедура: см.
`/administrativnoe-pravo:otvet-na-protokol-koap`. Права ниже — из 248-ФЗ и общих гарантий, не из
КоАП.

## Права проверяемого лица

### 1. Проверить полномочия проверяющих

- Служебные удостоверения проверяющих
- Решение о проведении контрольного (надзорного) мероприятия, с реквизитами
- Соответствие фактического состава проверяющих составу, указанному в решении
- Соответствие предмета мероприятия предмету, указанному в решении
- Срок мероприятия — не превышен ли

**Если что-то не сходится** — зафиксировать письменно; при явном несоответствии решению —
рассмотреть отказ в допуске (аккуратно, без создания видимости препятствования), связаться с
outside-адвокатом немедленно, вести собственную видео/аудиофиксацию (с уведомлением проверяющих).

### 2. Присутствие представителя

Право иметь как минимум одного представителя организации при всех действиях мероприятия; право
привлечь outside-адвоката ФПА.

### 3. Ознакомление с материалами

Право знакомиться с актами и документами, составляемыми в ходе мероприятия; право получить копии
всех материалов мероприятия.

### 4. Возражения

Право заявлять возражения в любой момент мероприятия (с занесением в протокол); право подавать
ходатайства о проведении дополнительных контрольных действий; право заявлять отвод проверяющему
при наличии оснований.

### 5. Конфиденциальность

Право на защиту коммерческой тайны (98-ФЗ); ограничение на разглашение персональных данных
третьих лиц без правового основания; сохранение банковской (ст. 26 закона о банках), врачебной и
иной охраняемой законом тайны.

### 6. Право не свидетельствовать против себя

Конституционная гарантия (ст. 51 Конституции РФ) — нет обязанности давать объяснения,
свидетельствующие против себя и близких родственников. Применяй аккуратно: формально она про
свидетельские показания, но на практике распространяется на любые объяснения при опросе.

## Workflow

### Шаг 1. Прибытие проверяющих

```markdown
## Прибытие проверяющих

### Проверка полномочий
- [ ] Удостоверения предъявлены
- [ ] Решение о проведении мероприятия № [N] от [ДД.ММ.ГГГГ] — копия получена
- [ ] Состав соответствует решению
- [ ] Предмет соответствует решению
- [ ] Срок мероприятия в пределах решения
- [ ] Применим ли мораторий для МСП — актуально ли для планового мероприятия

### Фиксация
- [ ] Журнал учёта проверок открыт (собственный)
- [ ] Собственная фиксация начата (с уведомлением)
- [ ] Свидетели со стороны организации присутствуют
```

### Шаг 2. Передача документов

**Критично: не передавать больше, чем запрошено.**

```markdown
## Протокол передачи документов

### Уточнить конкретный запрос
- «Какие именно документы?»
- «За какой период?»
- «В какой форме?»

### Подготовка копий
- Оригиналы — предъявить и вернуть, не передавать без прямой необходимости
- Копии — предоставлять по запросу
- Опись передаваемого с постраничной нумерацией

### Пометки конфиденциальности
Для каждого документа, содержащего:
- Коммерческую тайну (режим 98-ФЗ) — явная маркировка
- ПДн третьих лиц — минимизировать/обезличить, где возможно
- Материалы, защищённые адвокатской тайной (ФЗ-63, если привлечён outside-адвокат) — не раскрывать

### Запросы за пределами предмета
Если запрошено то, что выходит за рамки заявленного предмета мероприятия:
- Вежливо отказать
- Зафиксировать письменно: «Запрос выходит за рамки предмета мероприятия от [ДД]»
- Не предоставлять
- Отметить для последующих возражений
```

### Шаг 3. Опросы сотрудников

**Критично: не давать показания без ответственного за комплаенс/outside-адвоката.**

```markdown
## Протокол опроса

### Перед началом
- [ ] Установлен опрашивающий (ФИО, должность)
- [ ] Установлен опрашиваемый
- [ ] Присутствие ответственного за комплаенс/outside-адвоката подтверждено
- [ ] Опрашиваемый понимает свои права

### Во время опроса
Опрашиваемый вправе:
- Не давать объяснения (ст. 51 Конституции РФ)
- Отвечать в письменной форме
- Получить копию своих объяснений
- Внести замечания в протокол опроса

Опрашиваемому следует избегать:
- Предположений и домыслов
- Признаний без предварительного анализа последствий
- Добровольного предоставления информации сверх заданного вопроса

Рекомендуемый подход: «Мне нужно время, отвечу в письменной форме» — с последующей документацией
всего сказанного.

### При давлении/угрозах
- Прекратить опрос
- Зафиксировать обстоятельства
- Немедленно привлечь outside-адвоката
- Рассмотреть жалобу вышестоящему органу/прокуратуре
```

### Шаг 4. Ежедневная фиксация

```markdown
## Журнал мероприятия за день

- **Дата:** [ДД.ММ.ГГГГ]
- **Действия проверяющих:** [...]
- **Переданные документы:** [...]
- **Проведённые опросы:** [опрашиваемый, время, темы]
- **Замечания/спорные моменты:** [...]
- **Фото/записи, сделанные проверяющими:** [перечень]
```

### Шаг 5. Особые ситуации

**Изъятие документов.** Допустимо только по установленным процедурам (для мер, требующих судебной
санкции, — при её наличии). Без надлежащей санкции — незаконно. Фиксировать всё (видео, если
возможно), немедленно привлечь outside-адвоката, опись изъятого подписывать только после
внимательной проверки.

**Осмотр помещений.** Должен проходить в присутствии представителя организации, строго в рамках
предмета мероприятия. Вести параллельную фиксацию (фото, замеры) со своей стороны.

**Контрольная закупка/эксперимент.** Проверяющие вправе проводить в отдельных категориях
мероприятий — должна быть документирована.

### Шаг 6. Завершение мероприятия — акт

```markdown
## Акт мероприятия

### Перед подписанием
- [ ] Прочитан полностью
- [ ] Соответствие фактическим обстоятельствам проверено
- [ ] Выявленные нарушения — согласие/несогласие по каждому
- [ ] Указанные нормы — сверены

### Варианты подписания

#### A. Подписать без возражений
Принимаются все выводы акта. Риск: закреплённое согласие ограничивает дальнейшее обжалование.

#### B. Подписать с отметкой о возражениях
Отметка вида «С актом ознакомлен(а). Письменные возражения будут представлены в установленный
срок». Рекомендуемый подход по умолчанию — сохраняет право на дальнейшую позицию.

#### C. Отказ от подписания
Составляется акт об отказе от подписи, право на дальнейшее обжалование не утрачивается.
Вариант B обычно предпочтительнее — меньше выглядит как уклонение.

### После подписания
- Получить копию акта
- Опись всех приложенных документов
- Запланировать подготовку возражений
```

### Шаг 7. Действия после проверки

```markdown
## Workflow после мероприятия

### В течение 7 дней
- [ ] Внутренний разбор — что прошло хорошо/плохо
- [ ] Систематизация собранных актов/документов
- [ ] Предварительная оценка вероятных выводов

### В срок, установленный для возражений на акт
- [ ] Письменные возражения на акт поданы (точный срок — по применимому регламенту, часто
      ориентир 15 рабочих дней в практике конкретных регуляторов —
      `[проверить точный срок по первоисточнику для конкретного регулятора]`)
- [ ] Outside-адвокат ФПА привлечён при материальном деле

### Если выдано предписание
- Соблюсти срок исполнения, если согласны
- Либо обжаловать в обязательном досудебном порядке (гл. 9, ст. 39–40 248-ФЗ — с 01.01.2023
  обязателен для субъектов предпринимательской деятельности `[сверено 2026-08-27]`), затем при
  необходимости — в суд

### Если возбуждено дело об административном правонарушении
→ `/administrativnoe-pravo:otvet-na-protokol-koap`
```

## Частые ошибки

**Критичные:**
- Подписание акта без предварительного review — закрепляет согласие, ограничивает обжалование.
- Добровольное предоставление информации за пределами предмета мероприятия — расширяет его охват.
- Признательные показания под давлением, без юриста, — становятся доказательством.
- Отсутствие собственной фиксации — невозможно позже доказать, что нарушений не было или что
  процедура нарушена.
- Отказ от привлечения outside-адвоката при материальном деле.

**Существенные:**
- Не зафиксированы процессуальные нарушения проверяющих (запись, даты и т.д.).
- Неупорядоченная передача документов — создаёт впечатление сокрытия.
- Противоречивые ответы у разных сотрудников.

**Хорошая практика:**
- Спокойная, профессиональная манера поведения.
- Документировать всё.
- «Отвечу позже» предпочтительнее спонтанных предположений.
- Outside-адвокат на связи всё время мероприятия.

## Чего не делает

- Не занимается устранением содержательных нарушений комплаенса.
- Не ведёт переговоры с проверяющими по существу — в материальных делах это зона outside-адвоката.
- Не заменяет формальную юридическую консультацию для материальных ситуаций.
