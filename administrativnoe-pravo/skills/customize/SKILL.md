# /customize

## Когда запускается
Пользователь ввёл `/administrativnoe-pravo:customize` — хочет изменить что-то в профиле
административной практики без перезапуска cold-start и без ручной правки.

## Что делать

1. **Прочитай конфиг** `~/.claude/plugins/config/claude-for-legal-ru/administrativnoe-pravo/CLAUDE.md`
   (и `~/.claude/plugins/config/claude-for-legal-ru/company-profile.md` уровнем выше). Если
   конфига нет или в нём плейсхолдеры:
   > Настройка ещё не запускалась. Сначала `/administrativnoe-pravo:cold-start-interview` —
   > customize правит уже существующий профиль.

2. **Покажи карту настраиваемого** с текущими значениями одной строкой:
   - **Компания / кто мы** — наименование, ОПФ *(общее для всех плагинов — меняется в
     `company-profile.md`)*
   - **Сторона клиента и тип субъекта** — привлекаемое лицо (ЮЛ / ИП / должн.лицо / физлицо)
   - **Регуляторный ландшафт** — ОКВЭДы, применимые регуляторы, статус МСП/мораторий
   - **Открытые дела** — проверки, протоколы, постановления, жалобы, дисквалификации, по каждому
     стадия производства
   - **Позиции практики** — порог эскалации outside-адвокату, кто ведёт комплаенс
   - **Ведение дел** — режим, активное дело (живёт в `dela/_sostoyanie.md`)

3. **Спроси, что менять:**
   > Что поправить? Выберите секцию или опишите изменение своими словами.

4. **Внеси точечное изменение** в конфиг, покажи diff «было → стало», подтверди. Не трогай другие
   секции. Если меняется общая для плагинов сущность (компания) — правь в `company-profile.md` и
   предупреди, что изменение затронет все плагины форка.

5. **Подтверди:** «Готово. `[секция]`: было `[X]` → стало `[Y]`. Остальное не тронул.»

## Пример
```
/administrativnoe-pravo:customize
У нас теперь открыта внеплановая проверка Роспотребнадзора, добавь в открытые дела
```
