# Установление бенефициарного владельца

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/protivodejstvie-otmyvaniyu/CLAUDE.md`. Файла
нет или в нём `[ЗАПОЛНИТЬ]` — стоп, направь на
`/protivodejstvie-otmyvaniyu:cold-start-interview`. Без настройки работает только cold-start.

Если включён режим `vedenie-del` и есть активное дело (например, комплаенс-досье клиента) —
результат каскадного анализа и вывод о бенефициарах пиши в реестр дела, не держи в памяти диалога.

## Назначение

Установить бенефициарных владельцев (БВ) юридического лица — клиента. Требуется для:
- идентификации клиента по 115-ФЗ (`/identifikatsiya-klienta`);
- последующей проверки БВ по санкционным спискам и спискам ПДЛ
  (`/proverka-sanktsionnyh-spiskov`, `/proverka-pdl`);
- раскрытия сведений о БВ по запросу уполномоченного органа (ст. 6.1 115-ФЗ).

## Определение бенефициарного владельца (ст. 3 115-ФЗ)

Физическое лицо, которое:
- **прямо или косвенно** (в том числе через цепочку третьих лиц) **владеет** более **25%** в
  капитале юридического лица-клиента, **либо**
- **имеет возможность контролировать действия клиента**, в том числе через иные формы контроля,
  не сводящиеся к доле участия

`[проверить точную формулировку ст. 3 по первоисточнику на дату вопроса]`

**Ключевые элементы:**
- «в конечном счёте» — если прямой участник сам юридическое лицо, разбор продолжается до
  физического лица;
- «иным образом контролирует» — существо отношений важнее формы участия.

## Шаг 1. Прямые участники

```markdown
## Юридическое лицо A: [название + ИНН]

### Прямые участники (по ЕГРЮЛ)

| # | Участник | Доля |
|---|----------|------|
| 1 | ООО «Альфа» (ИНН XX) | 60% |
| 2 | Иванов И. И. | 30% |
| 3 | ООО «Бета» (ИНН YY) | 10% |
```

## Шаг 2. Разбор каскада — куда указывает каждый участник-юридическое лицо

```markdown
### ООО «Альфа» (60% в юридическом лице A)

#### Участники

| # | Участник | Доля |
|---|----------|------|
| 1 | Петров П. П. | 50% |
| 2 | АО «Гамма» (ИНН ZZ) | 50% |

#### АО «Гамма» (50% в ООО «Альфа»)

##### Акционеры

| # | Акционер | Доля |
|---|----------|------|
| 1 | Сидоров С. С. | 100% |
```

## Шаг 3. Расчёт эффективной доли участия

```markdown
## Расчёт по каскаду

### Иванов И. И.
- Прямая доля в A: 30%
- **Эффективная доля:** 30% (> 25%)
- → **БЕНЕФИЦИАРНЫЙ ВЛАДЕЛЕЦ**

### Петров П. П.
- Через ООО «Альфа» (50%), которая владеет 60% в A
- Эффективная доля: 50% × 60% = **30%**
- → **БЕНЕФИЦИАРНЫЙ ВЛАДЕЛЕЦ** (> 25%)

### Сидоров С. С.
- Через АО «Гамма» (100%) → ООО «Альфа» (50%) → A (60%)
- Эффективная доля: 100% × 50% × 60% = **30%**
- → **БЕНЕФИЦИАРНЫЙ ВЛАДЕЛЕЦ**

### ООО «Бета» (10% в юридическом лице A)
- Прямая доля 10% < 25% — не бенефициар через цепочку участия
- Если есть контроль за пределами владения (например, по корпоративному договору) — отдельный
  анализ по Шагу 4

## Бенефициарные владельцы юридического лица A

1. Иванов И. И. — 30% прямо
2. Петров П. П. — 30% через ООО «Альфа»
3. Сидоров С. С. — 30% через АО «Гамма» → ООО «Альфа»
```

## Шаг 4. Проверка контроля за пределами владения

Случаи, когда физическое лицо может быть БВ без прямой/косвенной доли свыше 25%:

| Механизм | Возможный БВ |
|---|---|
| Номинальный держатель / доверительный управляющий | реальный бенефициар по соглашению |
| Управляющая компания | лицо, контролирующее управляющую компанию |
| Корпоративный договор с правом вето | лицо с правом вето |
| Опционы / конвертируемые инструменты | лицо с правом на конвертацию |
| Семейная структура владения | фактический глава структуры |

`[закрытого перечня форм контроля в ст. 3 115-ФЗ нет — не воспроизводить как исчерпывающий список]`

## Шаг 5. Документирование

```markdown
## Бенефициарные владельцы [юридическое лицо A]

### БВ 1: Иванов Иван Иванович
- Дата рождения: [ДД.ММ.ГГГГ]
- Гражданство: РФ
- Документ, удостоверяющий личность: [реквизиты]
- Адрес: [...]
- ИНН: [...]
- Способ обладания: прямое участие 30% в уставном капитале

### БВ 2: Петров Пётр Петрович
- ...
- Способ обладания: косвенное участие 30% через ООО «Альфа»

## Иные лица, контролирующие действия клиента

[если есть — контроль вне владения]

## Источники сведений

- Выписка из ЕГРЮЛ на [ДД.ММ.ГГГГ]
- Учредительные документы (приложение)
- Корпоративный договор (если есть и доступен)
- Заявление клиента + документы, удостоверяющие личность БВ
```

## Шаг 6. Действия при выявлении

**Проверка каждого БВ по спискам** — `/proverka-sanktsionnyh-spiskov` и `/proverka-pdl`.

**Раскрытие по запросу уполномоченного органа (ст. 6.1 115-ФЗ).** Юридическое лицо обязано
располагать сведениями о своих БВ, обновлять их не реже одного раза в год и предоставлять по
запросу Росфинмониторинга, ФНС и иных уполномоченных органов — это не публикация в открытом
доступе, а раскрытие адресату запроса `[проверить актуальный перечень уполномоченных органов и
периодичность обновления по первоисточнику]`.

**Периодическая переверификация** — не реже раза в год, а также при любых корпоративных
изменениях (новые участники, реорганизация).

## Признаки повышенного риска

**Блокирующие:**
- невозможно установить БВ (непрозрачная структура с трастом в юрисдикции с низкой прозрачностью)
  — остановиться, рассмотреть отказ либо усиленную проверку (`/identifikatsiya-klienta`, EDD);
- БВ в санкционном списке — заморозка операций;
- БВ — публичное должностное лицо без раскрытия этого статуса — усиленная проверка;
- признаки номинальных директоров/участников — отказ либо усиленная проверка.

**Требуют дополнительного внимания:**
- БВ из недружественной страны — дополнительная проверка по контрсанкционным указам;
- каскад более 3 уровней — расширенное документирование;
- БВ отказывается раскрывать сведения — основание для подозрения, усиленная проверка.

**Не вызывают вопросов:**
- БВ — резидент РФ с прозрачной структурой бизнеса, не в списках, документы полны и
  непротиворечивы.

## Чего не делает

- Не вносит изменения в ЕГРЮЛ.
- Не подаёт сведения о БВ в уполномоченные органы — это ответственное лицо организации.
- Не принимает решение об отказе клиенту при отказе раскрыть БВ — это компетенция ответственного
  за ПОД/ФТ либо outside-адвоката.

## Правовая основа

- ст. 3 115-ФЗ (определение бенефициарного владельца)
- ст. 7 115-ФЗ (обязанность идентифицировать)
- ст. 6.1 115-ФЗ, введена Федеральным законом от 23.06.2016 № 215-ФЗ (обязанность располагать
  сведениями о БВ и раскрывать их по запросу уполномоченных органов)
- ст. 93.1 ФЗ-208 (для акционерных обществ — раскрытие информации)
