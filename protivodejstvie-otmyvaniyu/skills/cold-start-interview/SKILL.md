# /cold-start-interview

Пишет `~/.claude/plugins/config/claude-for-legal-ru/protivodejstvie-otmyvaniyu/CLAUDE.md` по
структуре шаблона плагина. Повтор с `--redo` — переинтервью с показом diff до перезаписи.

## Инструкции

1. **Проверь состояние конфига.** Есть `[ЗАПОЛНИТЬ]` — свежее интервью. Заполнен и `--redo` не
   передан — спроси, перезапускать ли.
2. **Веди по блокам, один блок за раз.** Записывай ответы словами пользователя.
3. **Прочитай `company-profile.md`** уровнем выше, если он есть: наименование, ОПФ повторно не
   спрашивай.
4. **Запиши конфиг**, создав родительские папки. Покажи сводку: «Вот что я услышал — что понял
   неверно?»

## Сценарий

### Блок 1. Тип организации и регулятор

- Тип организации — субъекта 115-ФЗ: кредитная организация / страховая / лизинговая / МФО /
  нотариус / адвокат / риелтор / аудитор / профессиональный участник рынка ценных бумаг / иное
  из перечня ст. 5 115-ФЗ?

  *Тип определяет объём требований: у кредитных организаций — полный объём и надзор Банка России;
  у нотариусов, адвокатов, риелторов, аудиторов — ограниченный объём, применимый только к
  определённым операциям (например, у риелтора — сделки с недвижимостью).*

- Регулятор: Банк России (кредитные, страховые, МФО, профучастники РЦБ) или Росфинмониторинг
  (остальные субъекты)?
- На чьей стороне работаем: сама организация — субъект 115-ФЗ / outside-консультант по
  комплаенсу?
- Статус представителя: адвокат ФПА / комплаенс-специалист без статуса адвоката / инхаус?

  *Влияет на то, что попадает под адвокатскую тайну (ст. 8 ФЗ-63), и на шапку рабочего продукта.*

### Блок 2. Ключевое для каждого скилла (не пропускать)

- Известен ли актуальный порог обязательного контроля на текущую дату? Предупреди: сумма порога
  (1 млн ₽ для большинства операций, не менее 5 млн ₽ для сделок с недвижимостью) и состав
  подконтрольных операций периодически уточняются подзаконными актами и приказами
  Росфинмониторинга — нельзя полагаться на цифру из памяти без сверки на дату вопроса.
- Есть ли открытые вопросы комплаенса: поданные сообщения в Росфинмониторинг, открытые проверки
  ЦБ/Росфинмониторинга, выявленные санкционные совпадения, клиенты на усиленной проверке (EDD)?
- Есть ли эпизоды, приближающиеся к уголовному риску по ст. 174/174.1 УК (легализация)?

### Блок 3. Комплаенс-инфраструктура

- Правила внутреннего контроля (ПВК) утверждены? Дата утверждения и последнего пересмотра?
- Назначено ли ответственное лицо (комплаенс-офицер / ответственный за ПОД/ФТ)? ФИО, дата
  назначения?
- Какая система используется для скрининга по спискам (санкции, ПДЛ) и для мониторинга операций —
  собственная разработка / вендор / вручную?
- Когда последний раз проводилось обучение сотрудников по ПОД/ФТ?

### Блок 4. Санкционная экспозиция

- Есть ли трансграничные операции, расчёты в иностранной валюте, корреспондентские отношения с
  иностранными банками?
- Есть ли среди клиентов лица из перечней Росфинмониторинга или под контрсанкционными указами
  Президента? Если да — какой план действий уже принят?

### Блок 5. Позиции практики

- Порог материальности, при котором дело эскалируется outside-адвокату ФПА?
- Источники, которые используем для санкционного скрининга?
- Что никогда не делаем? (например, «не онбордим клиента без завершённой идентификации
  бенефициаров»)

### Блок 6. Ведение дел

- Портфель ведёт плагин `vedenie-del`. Включить режим сейчас?

  *Сроки по 115-ФЗ короткие и жёсткие: 3 рабочих дня — на направление сведений в Росфинмониторинг
  как по операции обязательного контроля, так и по подозрительной операции; отдельно замораживание
  средств лица из перечня террористов/ОМП — незамедлительно, но не позднее 24 часов, а сообщение о
  применённой мере — не позднее следующего рабочего дня. Это другое действие. Режим снижает риск
  пропуска. Сроки исчисляет этот плагин, реестр их только хранит;
  каждый срок несёт поля «кто исчислил» и «кто проверил».*

### Блок 7. Что болит

- Что в комплаенс-рутине отнимает больше всего времени: онбординг клиентов, скрининг, подготовка
  ПВК, подача сообщений в Росфинмониторинг?
- Был ли за последние два года эпизод, где выявление подозрительной операции или совпадения по
  списку случилось с задержкой?

## После интервью

Предложи проверочный прогон: «Опишите клиента или операцию — покажу, что вижу». Напомни, что
каждый вывод плагина — проект для проверки практикующим специалистом по комплаенсу, и что при
приближении к уголовному риску по ст. 174/174.1 УК — немедленная эскалация outside-адвокату.
