# Проверка на статус публичного должностного лица

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/protivodejstvie-otmyvaniyu/CLAUDE.md`. Файла
нет или в нём `[ЗАПОЛНИТЬ]` — стоп, направь на
`/protivodejstvie-otmyvaniyu:cold-start-interview`. Без настройки работает только cold-start.

Если включён режим `vedenie-del` и есть активное дело — результат проверки пиши в досье клиента
в реестре дела.

## Назначение

Определить, является ли клиент, его бенефициарный владелец либо близкий родственник публичным
должностным лицом (ПДЛ). Статус ПДЛ требует усиленной проверки клиента.

## Категории ПДЛ по 115-ФЗ

### А. Иностранные публичные должностные лица (ИПДЛ)

Иностранные граждане, занимающие или занимавшие:
- высшие государственные должности (президенты, главы правительств, министры);
- высшие судебные, законодательные, военные должности;
- руководящие должности в центральных банках;
- должности послов и руководителей консульских учреждений;
- руководящие должности в государственных компаниях, имеющих существенное значение.

Через некоторое время после прекращения полномочий статус подлежит переоценке риска, но на
практике лицо часто продолжает восприниматься как связанное с прежним влиянием
`[проверить точный срок такой переоценки по первоисточнику — конкретный срок в самой норме не
установлен единообразно, встречающийся в практике трёхлетний ориентир проверить отдельно]`.

### Б. Должностные лица международных организаций (МПДЛ)

Высшее руководство ООН и его структур, международных финансовых организаций, институтов
Европейского союза, региональных международных организаций.

### В. Российские публичные должностные лица (РПДЛ)

С 2018 года (по указу Президента) включены в систему контроля ПДЛ:
- Президент РФ;
- Председатель Правительства РФ и заместители;
- федеральные министры;
- депутаты Государственной Думы и члены Совета Федерации;
- судьи Конституционного Суда и Верховного Суда;
- руководители федеральных органов исполнительной власти;
- главы субъектов РФ;
- послы РФ;
- руководство государственных корпораций и компаний с существенным государственным участием;
- Председатель Банка России и заместители.

`[перечень и год включения РПДЛ в систему контроля — 2018 год — проверить по первоисточнику: точная
дата и нормативный акт]`

### Г. Связанные лица

- супруг(а);
- дети;
- родители — если применимо в контексте конкретных отношений;
- иные близкие родственники.

## Порядок работы

### Шаг 1. Проверка идентифицирующих сведений

```markdown
## Проверяемое лицо

- **Имя:** [...]
- **Гражданство:** [...]
- **Должность:** [...]
- **Период занятия должности:** [...]
- **Связь с клиентом:** [сам клиент / супруг(а) / ребёнок / родитель / иное]
```

### Шаг 2. Поиск по источникам

- официальные сайты органов государственной власти (структура и состав руководства);
- открытые реестры и справочники организаций (для установления должностей в компаниях с
  государственным участием);
- коммерческие базы данных и системы проверки контрагентов;
- открытые источники: новостные архивы, официальные публикации;
- перечень российских ПДЛ, если организация ведёт собственный внутренний список на основании
  открытых данных о структуре органов власти.

`[перечень источников — рабочий, не закрытый; конкретный набор источников для проверки — по ПВК
организации]`

Стратегия поиска: точное совпадение имени; вариации (транслитерация, уменьшительные формы);
известные псевдонимы (для публичных фигур); поиск по супругам и близким родственникам (для
проверки связанных лиц).

### Шаг 3. Анализ результатов

#### Случай А. Действующее ПДЛ

→ Применить усиленную проверку:
- утверждение приёма на обслуживание руководством;
- установление источника происхождения состояния и средств;
- усиленный текущий мониторинг операций;
- периодический пересмотр — не реже раза в год;
- разумные меры по установлению статуса связанных лиц (членов семьи, близких соратников).

#### Случай Б. Бывшее ПДЛ

Оценка риска индивидуально по каждому случаю; при недавнем прекращении полномочий усиленная
проверка, как правило, сохраняется.

#### Случай В. Только связанное лицо

Усиленная проверка также применяется; фиксируется, что статус связанного лица раскрыт и
задокументирован.

#### Случай Г. Не ПДЛ

Стандартная проверка; поиск документируется как «проверено, совпадений не найдено».

### Шаг 4. Меры усиленной проверки для ПДЛ

**Утверждение руководством** — обязательно для приёма на обслуживание и для продолжения отношений
с ПДЛ, с документированием решения.

**Источник происхождения состояния** — объяснение происхождения накопленного состояния (карьера,
наследство, предпринимательская деятельность, инвестиции), с подтверждающими документами.

**Источник происхождения средств** — применительно к конкретным операциям, с подтверждающими
документами (записи о доходах, документы о продаже активов).

**Усиленный текущий мониторинг** — более частый пересмотр операций, пониженные пороги
алертирования, регулярное обновление досье (ежегодно).

### Шаг 5. Особенности применительно к РФ

**Пересечение с санкциями.** Значительная часть российских ПДЛ одновременно находится в
санкционных списках иностранных государств — перекрёстная проверка обязательна
(`/proverka-sanktsionnyh-spiskov`). При совпадении по обоим основаниям — повышенное внимание и,
как правило, отказ либо заморозка операций.

**Антикоррупционное законодательство (273-ФЗ).** Российские ПДЛ обязаны раскрывать сведения о
доходах в ежегодных декларациях; при доступности такой декларации — сверка с ней, значимые
несоответствия — основание для дополнительного внимания.

**Репутационный риск.** Публичное внимание к отношениям с ПДЛ существует даже при полностью
законных операциях — фактор для оценки риска организации, а не для оценки законности конкретной
операции клиента.

## Формат вывода

```markdown
# Проверка на статус ПДЛ — [имя]

## Идентификация

- **Имя:** [...]
- **Должность:** [...]
- **Страна:** [...]
- **Категория:** [ИПДЛ / МПДЛ / РПДЛ / связанное лицо / не ПДЛ]
- **Действующее / бывшее:** [...]

## Проверенные источники

- [✓] [источник 1]
- [✓] [источник 2]
- [✓] Открытые источники (новости, официальные публикации)
- [✓] Государственные реестры

## Перекрёстные проверки

- **Санкции:** [не найдено / совпадение найдено]
- **Негативная информация:** [находки]
- **Антикоррупционная декларация (для РПДЛ):** [подавалась ли, соответствие]

## Решение

[приём с усиленной проверкой / приём в стандартном порядке / отказ с обоснованием]

## Меры усиленной проверки (если применимо)

- [ ] утверждение руководством — ФИО, дата
- [ ] источник состояния задокументирован
- [ ] источник средств задокументирован по операциям
- [ ] усиленный мониторинг включён
- [ ] периодический пересмотр запланирован — ежегодно

## Документирование

- сохранено в досье клиента: [путь]
- график повторной проверки: [ежегодно / по событию]
```

## Чего не делает

- Не выполняет фактический приём с усиленной проверкой — это компетенция комплаенс-подразделения.
- Не публикует факт связи клиента с ПДЛ — это сведения ограниченного доступа.
- Не разбирает обращения регулятора — это outside-адвокат.

## Правовая основа

- ст. 7.3 115-ФЗ (определение ПДЛ и требование усиленной проверки)
- Положение Банка России от 18.06.2025 № 860-П (для кредитных организаций — заменило Положение
  № 375-П, утратившее силу 13.08.2025) `[сверено 2026-08-27]`
- ФЗ-273 «О противодействии коррупции»
