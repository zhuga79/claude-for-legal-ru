# /pdn-assessment — оценка обработки ПДн и вреда субъектам

Структурированная оценка обработки по ФЗ-152. **Важно:** в праве РФ нет прямого аналога GDPR-DPIA как обязательной универсальной процедуры; есть **оценка вреда, который может быть причинён субъектам** (ст. 18.1 ч. 5) и **модель угроз/определение уровня защищённости** (ПП-1119, приказы ФСТЭК № 21, ФСБ). Скилл готовит правовую часть оценки и указывает на техническую (модель угроз — зона ИБ, не этого скилла).

## Инструкции

1. **Загрузи профиль.** Плейсхолдеры → cold-start. Возьми карту обработок как контекст.
2. **Опиши обработку:** цель, категории ПДн и субъектов, объём/масштаб, источники, получатели, сроки, автоматизация/профилирование, локализация, трансграничность.
3. **Проверь правовую базу:**
   - Основание (ст. 6/9/10/11) — есть и подходит?
   - **Необходимость и соразмерность:** минимизация — не собираем ли избыточное относительно цели (ст. 5 ч. 5)? Цель конкретна и законна (ст. 5)?
   - Уведомление РКН (ст. 22), локализация (ст. 18 ч. 5), трансграничность (ст. 12) — статус.
4. **Оценка вреда субъектам (ст. 18.1 ч. 5).** По каждой угрозе — вероятность × тяжесть вреда (дискриминация, финансовые потери, репутация, утрата контроля над данными, риск для спец/био). Шкала 🔴/🟠/🟡/🟢.
5. **Меры снижения:** организационные (минимизация, разграничение доступа, обезличивание/псевдонимизация, сроки) и указатель на технические (уровень защищённости по ПП-1119, меры ФСТЭК № 21) — техчасть передать ИБ.
6. **Остаточный риск и вывод:** можно ли начинать/продолжать, при каких условиях, что эскалировать.

## Формат вывода

```markdown
[ШАПКА]

# Оценка обработки ПДн: [название]

## Обработка
[цель, категории, субъекты, масштаб, локализация, трансгранично]

## Правовая база
- Основание: [ст.] — ✅/❌ `[решить]`
- Необходимость/соразмерность (минимизация): [оценка]
- Уведомление РКН / локализация / трансгранично: [статус] `[проверить]`

## Оценка вреда субъектам (ст. 18.1 ч. 5)
| Угроза | Вероятность | Тяжесть вреда | Уровень |
|---|---|---|---|
| [угроза] | | | 🔴/🟠/🟡/🟢 |

## Меры снижения
- Организационные: [...]
- Технические (→ ИБ, ПП-1119 / ФСТЭК № 21): [указатель]

## Вывод
[Начинать / с условиями / нет]. Остаточный риск: [уровень]. Эскалация: [кому].
```

## Проверки перед выдачей
- [ ] Правовая часть отделена от технической (модель угроз — зона ИБ)
- [ ] Проверена минимизация (не собираем избыточное)
- [ ] Оценка вреда привязана к ст. 18.1 ч. 5, не к GDPR-DPIA
- [ ] Спец/био/трансгранично → эскалация по профилю
