# Workspace: claude-for-legal-ru — локализация юр-плагинов Claude под право РФ

## Purpose

Проект локализации набора юридических плагинов Claude (форк `anthropic/claude-for-legal`, Apache-2.0) под законодательство РФ. Цель — не покраска терминов, а переработка правового существа: ГК РФ, ТК РФ, НК РФ, УК/УПК РФ, АПК/ГПК РФ, ФЗ-152 «О персональных данных», ФЗ-98 «О коммерческой тайне» и др. Каждый плагин — редактируемый marketplace-плагин Claude Code. Истина живёт в этой папке; апстрим-кэш (`~/.claude/plugins/marketplaces/claude-for-legal`) НЕ редактируем.

Готово (эталон): плагин `dogovornoe-pravo` (локализация `commercial-legal`) — установлен и провалидирован.

## Folder Truth

- Локализацию вести ТОЛЬКО в этой папке-форке; апстрим-кэш плагинов не трогать (затрётся при обновлении).
- Оригинал — источник структуры и логики; правовое существо переписывается под РФ, а не переносится дословно.
- Файл, изменённый относительно оригинала, помечать в заголовке: «Локализация РФ на основе <оригинальный путь>».
- Не вносить клиентские ПД в плагины — это generic-код, публикуемый под Apache-2.0.

## Structure

- `.claude-plugin/marketplace.json` — манифест marketplace форка.
- `<plugin>/.claude-plugin/plugin.json` — манифест плагина.
- `<plugin>/CLAUDE.md` — шаблон профиля практики (читается скиллами по абсолютному пути конфига).
- `<plugin>/.mcp.json` — коннекторы (US/UK удалены; РФ-источники через paste-source).
- `<plugin>/skills/<name>/SKILL.md` — скиллы.
- `LICENSE` (Apache-2.0), `NOTICE` (атрибуция derivative work).
- `BRAIN.md`, `TASKS.md`, `LOG.md` — метаданные проекта Brain (этот воркспейс).

## Agent Rules

- Перед работой прочитать `BRAIN.md` и `TASKS.md`.
- Работать только внутри этой папки, если пользователь не указал иной путь.
- **Правовая корректность важнее скорости.** Слепая замена «US → РФ» в юр-существе запрещена: неверная квалификация хуже пустого шаблона.
- Ссылаться на конкретные нормы (ГК/ФЗ/УПК/АПК); неустоявшееся/непроверенное помечать `[проверить]` / `[знания модели — проверить]`.
- **Scope плагина = core + дешёвая обвязка** (ADR-002). До начала локализации классифицировать каждый апстрим-скилл: (a) правовое существо — переработать под нормы РФ, переносить всегда; (b) generic-обвязка без правовой специфики (workspace, трекеры, summary) — переносить, если ≈0.5–1 сессия и функция нужна соло/малой практике; (c) конструкция опирается на институт, которого нет в праве РФ (DMCA, deposition, subpoena от стороны, privilege log, FMLA-leave, NPRM comments) — не переносить и не публиковать под видом РФ-скилла. Полный паритет с апстримом не требуется. Таблицу классификации фиксировать в `LOG.md` до сборки плагина.
- Каждый вывод плагина — ПРОЕКТ для проверки практикующим юристом (адвокатом), а не юр. консультация. Сохранять guardrails оригинала.
- В РФ нет доктрины work-product; адвокатская тайна (ст. 8 ФЗ-63) — только для адвокатов. Не проставлять адвокатскую шапку не-адвокату.
- Перед коммитом: `claude plugin validate <plugin>`; для проверки — переустановка и прогон `cold-start` на реальном документе.
- Сохранять `NOTICE` и пометки о derivative work (условие Apache-2.0).
- Существенные действия писать в `LOG.md`.
