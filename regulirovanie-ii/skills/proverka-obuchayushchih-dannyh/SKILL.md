# Проверка обучающих данных

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/regulirovanie-ii/CLAUDE.md`. Файла нет или
в нём остались `[ЗАПОЛНИТЬ]` — стоп: «Плагину нужна настройка, запусти
`/regulirovanie-ii:cold-start-interview`.»

**Применимость.** Этот скилл — только для организаций, которые сами обучают или дообучают модель.
Если организация лишь потребляет чужой API (OpenAI/Anthropic/YandexGPT/GigaChat и подобное) — этот
скилл не нужен, вопросы про обучающие данные вендора закрывает `proverka-postavshchika-ii` (пункт
K — заверения вендора).

Если включён режим `vedenie-del` и есть активное дело — результат пиши в папку дела.

## Категории источников обучающих данных

- **A. Внутренние данные:** переписка с клиентами, внутренние документы, данные сотрудников,
  бизнес-транзакции.
- **B. Публичные данные:** открытые корпуса, Википедия, научные работы в общественном достоянии,
  открытые датасеты.
- **C. Купленные/лицензированные данные:** коммерческие датасеты от вендоров, архивы под лицензией.
- **D. Пользовательский контент:** посты в соцсетях/на форумах, отзывы (если у организации своя
  платформа).
- **E. Синтетические данные:** сгенерированные на основе реальных или полностью искусственные.

## Разбор по направлениям

### A. Соответствие 152-ФЗ

**Выявление ПДн в данных.**
```markdown
## Оценка наличия ПДн
- [ ] Имена / контакты
- [ ] Адреса
- [ ] Идентификаторы (ИНН, СНИЛС, паспортные данные)
- [ ] Биометрия
- [ ] Сведения о здоровье (специальная категория — ст. 10)
- [ ] Политические/религиозные взгляды, сведения о сексуальной жизни (специальная категория)
- [ ] Фото/голос — потенциально идентифицирующие
- [ ] Квази-идентификаторы (сочетание даты, локации, демографии — могут идентифицировать в
      совокупности)

Если найдено что-либо из перечня — применяется 152-ФЗ.
```

**Правовое основание для использования ПДн в обучении.**

| Основание | Когда применимо | Что нужно задокументировать |
|---|---|---|
| Согласие субъекта (п. 1 ч. 1 ст. 6) | Согласие явно охватывает обучение AI-модели | Запись согласия + чётко описанная область применения |
| Договор (п. 5 ч. 1 ст. 6) | Обучение необходимо для оказания услуги по договору с субъектом | Договор + обоснование необходимости именно для обучения |
| Законный интерес оператора (п. 7 ч. 1 ст. 6) | Интерес оператора не нарушает права и свободы субъекта | Документированная оценка баланса интересов |
| Общедоступность (п. 10 ч. 1 ст. 6) | Данные сделаны общедоступными самим субъектом | Документация источника — что и кем раскрыто |

Без правового основания использовать ПДн для обучения нельзя.

**Обезличивание.** После надлежащего обезличивания данные перестают быть ПДн (ст. 3 152-ФЗ) — но
риск повторной идентификации по совокупности признаков нужно оценивать отдельно, особенно на
насыщенных данных. Прямые идентификаторы (имена, контакты) — обязательный минимум для удаления;
квази-идентификаторы требуют более аккуратной обработки.

**Специальная категория ПДн (ст. 10).** Раса, этническое происхождение, политические взгляды,
религиозные/философские убеждения, сведения о здоровье, биометрия для идентификации, сведения о
сексуальной жизни, судимость. Использование требует отдельного явного согласия либо одного из
ограниченных оснований ст. 10 — повышенное внимание при аудите источника.

### B. Соответствие авторскому праву

**В праве РФ нет доктрины fair use** — в отличие от США, лицензирование обязательно, «добросовестное
использование» в смысле американского права здесь не работает как защита.

| Тип источника | Риск | Что снижает риск |
|---|---|---|
| Новостные статьи | Высокий | Только лицензированные датасеты |
| Книги | Высокий | Только общественное достояние или лицензия |
| Код (репозитории) | Средний | Проверка лицензии каждого репозитория, сохранение условий open-source лицензии |
| Изображения | Высокий | Стоковые лицензии либо CC-BY/CC0 |
| Музыка/аудио, видео | Высокий | Только лицензированные |
| Тексты с открытой лицензией (напр. CC-BY-SA) | Низкий | Атрибуция, соблюдение share-alike |
| Научные статьи | Средний | Открытый доступ (CC) — приемлемо; платный доступ — отдельная проверка условий |

**Опоры в ГК РФ:** ст. 1270 (исключительное право, использование только с согласия правообладателя
или по закону); ст. 1274 (цитирование/использование в научных, учебных, культурных целях — узкое
исключение, не покрывает коммерческое обучение модели); ст. 1281 (переход произведения в
общественное достояние — 70 лет после смерти автора). Лицензия CC-BY требует атрибуции; CC-NC
исключает коммерческое использование, включая обучение коммерческой модели.

**Исключение по ст. 10 ч. 2 243-ФЗ (с 01.03.2027).** Разработчик может использовать охраняемые
объекты авторского права для обучения **суверенной или национальной** модели без согласия
правообладателя и без выплаты вознаграждения, если объект правомерно введён в оборот или
общедоступен и правообладатель не ограничил доступ к нему техническими средствами — то есть модель
opt-out через технические меры защиты, а не через одну лишь оговорку в пользовательском соглашении
источника `[сверено 2026-08-27]`. Исключение **не действует** для моделей без статуса суверенной/
национальной (условия статуса — см. `reestr-sistem-ii`) и не действует до 01.03.2027. До этой даты
и для моделей без статуса — обычные правила лицензирования выше.

### C. Фильтрация запрещённого контента

```markdown
## Проверка на запрещённый контент
- [ ] Экстремистские материалы (ст. 1 ФЗ-114 — запрет распространения)
- [ ] Материалы уголовного характера
- [ ] Материалы сексуального характера
- [ ] Контент с участием несовершеннолетних
- [ ] Контент о суициде/самоповреждении
- [ ] Дезинформация
- [ ] Сведения, дискредитирующие Вооружённые Силы РФ (ст. 20.3.3 КоАП — предмет для фильтрации
      контента, который модель не должна воспроизводить/генерировать)
```
Без фильтрации — модель может воспроизводить такой контент в выводах, что создаёт риск для
организации независимо от того, что источник данных формально не её собственный.

### D. Практические особенности источников

Доступность отдельных зарубежных публичных датасетов может быть технически ограничена (геоблокировка
хостинга) — это операционный риск доступа, а не правовая категория. Российские государственные
открытые данные (data.gov.ru и подобные) — обычно без ограничений использования, но лицензионные
условия конкретного набора данных проверяются отдельно, не предполагаются автоматически.

### E. Качество и репрезентативность

```markdown
- [ ] Данные репрезентативны для той группы, которой будет служить модель?
- [ ] Покрытие подгрупп достаточно?
- [ ] Качество разметки проверено?
- [ ] Актуальность данных приемлема?
- [ ] Выбросы/шум обработаны?
- [ ] Дисбаланс классов учтён?
```

## Workflow

### Шаг 1. Инвентаризация источников

```markdown
| # | Источник | Тип | Объём | Лицензия | ПДн? | Риск |
|---|---|---|---|---|---|---|
| 1 | Внутренние переписки 2023–2025 | Внутренний | 1 млн диалогов | Внутреннее использование | Да (имена, содержание) | 🟡 |
| 2 | Википедия RU | Публичный | 5 ГБ | CC-BY-SA | Нет | 🟢 |
| 3 | Обращения в поддержку | Внутренний | 500 тыс. | Внутреннее использование | Да | 🟡 |
| 4 | Отраслевые статьи (куплены) | Лицензированный | 100 ГБ | Лицензия вендора | Возможно (авторы) | 🟢 |
| 5 | Скрейп новостей 2024 | Публичный без лицензии | 50 ГБ | Отсутствует | Да (упомянутые лица) | 🔴 |
```

### Шаг 3. Находки и меры

```markdown
### 🔴 Критично
1. **Скрейп новостей (источник 5)** — риск нарушения авторских прав + ПДн без правового основания

### 🟡 Средне
1. **Внутренние переписки (источник 1)** — использование ПДн в обучении требует правового основания
   → обезличить перед обучением либо задокументировать законный интерес

### 🟢 Приемлемо
[Википедия, лицензированные статьи]
```

### Шаг 4. План устранения

```markdown

- [ ] Проверить лицензированные альтернативы для замены
```

период, известные проблемы, применённые меры.

## Чего не делает

- Не выполняет само обезличивание — это задача инженерной команды.
- Не заключает лицензии — это закупки/юрист по IP.
- Не заменяет полноценный юридический разбор для коммерчески значимой модели — привлекай
  outside-адвоката или консультанта по интеллектуальной собственности.
