# Проверка документации закупки

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/gosudarstvennye-zakupki/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/gosudarstvennye-zakupki:cold-start-interview`.

Сторона поставщика-участника — решение об участии до вложения ресурсов в подготовку заявки. Заказчик
может использовать этот же чек-лист для самопроверки собственной документации до размещения (см.
`priznaki-zatochennosti-zakupki` для акцента на заточенности).

Если включён режим `vedenie-del` — все даты (подача заявок, подведение итогов, заключение
контракта) пиши в реестр дела сразу на Шаге 1, не держи в памяти диалога.

## Pre-flight

- Источник: ЕИС закупки (zakupki.gov.ru) либо профильная ЭТП.
- Применимый закон: 44-ФЗ / 223-ФЗ — определяет, какой раздел ниже применять буквально
  (44-ФЗ), а какой — как ориентир, требующий сверки с Положением о закупке заказчика (223-ФЗ).
- Способ определения поставщика: электронный аукцион / открытый конкурс / конкурс с ограниченным
  участием / запрос котировок / запрос предложений / закупка у единственного поставщика (обычно
  неприменимо к внешнему участнику).

## Workflow

### Шаг 1. Базовые параметры

```markdown
## Закупка №[...] в ЕИС

- Заказчик: [наименование, ИНН, уровень — федеральный/региональный/муниципальный/гос.корпорация]
- Регулирование: 44-ФЗ / 223-ФЗ
- Способ определения поставщика: [...]
- НМЦК: [сумма]
- Источник финансирования: [бюджет / собственные средства заказчика / иное]
- Дата размещения: [ДД.ММ.ГГГГ]
- Срок подачи заявок: [ДД.ММ.ГГГГ ЧЧ:ММ] ← дедлайн, зафиксировать в реестр дела
- Дата подведения итогов (ожидаемая): [ДД.ММ.ГГГГ]
- Срок исполнения контракта: [...]
```

### Шаг 2. Техническое задание

| Элемент | Проверка |
|---|---|
| Описание объекта закупки | Достаточно конкретно? Выполнимо для нас? |
| Технические характеристики | Соответствуют нашему ассортименту/возможностям? |
| ГОСТ / ТУ / сертификаты | Есть в наличии или получимы до подачи? |
| Брендовые требования без «или эквивалент» | Флаг — см. `priznaki-zatochennosti-zakupki` |
| Узкие технические параметры | Флаг заточенности |
| Сроки поставки/выполнения | Реалистичны для нас? |
| Условия поставки | Логистика возможна? |
| Гарантия | Срок и условия приемлемы? |
| Шеф-монтаж / обучение персонала заказчика | Есть ресурсы, если требуется? |

### Шаг 3. Требования к участникам

См. `proverka-dopuska-k-zakupke` для полного чек-листа единых и дополнительных требований (44-ФЗ)
либо требований Положения о закупке (223-ФЗ). Здесь — только вывод: пройдены/не пройдены, ссылка
на детальный отчёт.

### Шаг 4. Обеспечение

**A. Обеспечение заявки** (ст. 44 44-ФЗ) — при НМЦК свыше порога, установленного законом, заказчик
обязан включить требование в извещение `[проверить актуальный порог на дату вопроса]`. Размер —
от 0,5% до 5% НМЦК в зависимости от суммы закупки и способа `[сверено диапазон в общем виде
2026-08-27, точные ступени по сумме — проверить по актуальной редакции ст. 44]`. Форма: денежные
средства (спецсчёт на ЭТП) либо независимая гарантия (ст. 45 44-ФЗ). Срок действия гарантии —
не менее чем на 1 месяц дольше срока подачи заявок. Гос./муниципальные учреждения от обеспечения
заявки освобождены.

**B. Обеспечение исполнения контракта** (ст. 96 44-ФЗ) — стандартный диапазон 5–30% НМЦК. Льготы
для МСП — сниженный размер либо освобождение при наличии опыта исполнения аналогичных контрактов
без штрафных санкций `[проверить конкретные условия льготы на дату вопроса]`.

**C. Антидемпинговые добавки** (ст. 37 44-ФЗ) — при снижении цены на 25% и более от НМЦК:
обеспечение исполнения увеличивается **в 1,5 раза** от размера, установленного в документации, но
не менее 10% НМЦК/цены контракта `[сверено 2026-08-27]`. Для закупок с НМЦК от 15 млн ₽ —
дополнительно требуется представить обоснование добросовестности либо подтверждение реалистичности
цены (ст. 37 ч. 2), и снимается право на авансирование. Детали расчёта — см.
`zayavka-cenovaya-chast`.

**D. Обеспечение гарантийных обязательств** (ст. 96 ч. 2.2) — опционально по решению заказчика,
до 10% НМЦК, активируется на гарантийный период после исполнения.

### Шаг 5. Форма заявки

- **Аукцион** — первая часть (согласие с условиями + конкретные показатели товара, если требуется)
  и вторая часть (сведения об участнике, подтверждающие документы, декларации).
- **Конкурс** — единая заявка с техническим и ценовым предложением плюс подтверждающие документы,
  оцениваемая по критериям, указанным в документации (не только цена).

### Шаг 6. Проект контракта — на что смотреть внимательно

- **Твёрдая цена** без оговорок об индексации — риск при длинных сроках исполнения.
- **Сроки исполнения** — реалистичны ли для нас с учётом штрафов за просрочку (пеня — исходя из
  1/300 ключевой ставки ЦБ за день просрочки, если иное не установлено документацией
  `[проверить формулу и актуальную ключевую ставку на дату расчёта — mcp__ru-cbr__get_key_rate,
  если подключён]`).
- **Гарантийные обязательства** — срок и объём не избыточны ли относительно рынка.
- **Условия оплаты** — постоплата / аванс; для закупок у СМП по условиям заказчика нередко
  предусматривается авансирование `[проверить, обязательно ли это по действующей редакции ст. 30
  на дату вопроса — единой безусловной нормы об обязательном авансе для всех закупок у СМП в
  прежнем виде проверить по первоисточнику]`.
- **Изменение существенных условий контракта** (ст. 95 44-ФЗ) — допускается по ограниченному
  перечню оснований, как правило в пределах 10% от цены/объёма, только по соглашению сторон.

### Шаг 7. Признаки заточенности

Краткая сверка — полный разбор в `priznaki-zatochennosti-zakupki`: брендовая эксклюзивность без
«или эквивалент», узкие параметры под одного поставщика, аффилированность заказчика и вероятного
победителя, искусственно заниженный НМЦК.

### Шаг 8. Критерии оценки (для конкурсов)

Не только цена — качество, опыт, квалификация персонала и иные критерии по весам, указанным в
документации. Если веса сильно смещены в сторону, где мы слабы, — риск проигрыша даже при лучшей
цене.

## Чего не делает

- Не подаёт заявку через ЭТП — действие самого участника с его УКЭП.
- Не оформляет банковскую гарантию — это банк.
- Не готовит жалобу в ФАС — это `zhaloba-v-fas`.
