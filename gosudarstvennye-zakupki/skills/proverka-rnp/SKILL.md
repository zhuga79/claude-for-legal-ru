# Проверка РНП

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/gosudarstvennye-zakupki/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/gosudarstvennye-zakupki:cold-start-interview`.

Применимо к обеим сторонам: поставщик проверяет себя перед подачей заявки и проверяет
субподрядчиков/партнёров; заказчик — как инструмент due diligence участника перед допуском к
закупке.

Если включён режим `vedenie-del` и обнаружено активное попадание в РНП — срок на административное
обжалование и срок на судебное оспаривание пиши в реестр дела.

## Зачем проверять

1. Допуск к конкретной закупке (наш статус) — дополняет `proverka-dopuska-k-zakupke`.
2. Due diligence контрагента/партнёра перед коммерческой сделкой (репутационный риск).
3. Скрининг субподрядчика перед привлечением на гос.заказ.

## РНП — два разных реестра, проверяй оба при необходимости

| | РНП по 44-ФЗ | РНП по 223-ФЗ |
|---|---|---|
| Норма | ст. 104 44-ФЗ | ст. 5 223-ФЗ |
| Ведёт | ФАС России | ФАС России, отдельным реестром |
| Срок нахождения | 2 года | 2 года |
| Последствие для закупок по 44-ФЗ | автоматическая дисквалификация | НЕ дисквалифицирует автоматически (запрет для заказчика по 44-ФЗ действует только от записи в РНП по 44-ФЗ) |
| Последствие для закупок по 223-ФЗ | заказчик вправе потребовать отсутствия в обоих реестрах в своей документации | автоматическая дисквалификация для закупок этого заказчика, если так предусмотрено Положением |

`[сверено 2026-08-27]` Это раздельные списки с разным основанием включения — попадание в один не
означает попадание в другой, и наоборот.

## Workflow

### Шаг 1. Поиск

- **Источник:** ЕИС закупки (zakupki.gov.ru → раздел «Реестр недобросовестных поставщиков»,
  отдельные разделы для 44-ФЗ и 223-ФЗ).
- Параметры поиска: ИНН (точнее) или полное наименование + регион.

### Шаг 2. Что фиксировать по найденной записи

| Поле | Значение |
|------|----------|
| Наименование, ИНН, ОГРН контрагента | точное совпадение с проверяемым лицом |
| Дата включения / дата истечения 2-летнего периода | критично для решения |
| Причина включения | конкретное нарушение (уклонение от заключения контракта, существенное нарушение условий, расторжение по решению суда/заказчика) |
| Заказчик, инициировавший включение | |
| Реквизиты решения ФАС / судебного акта | нужны для возможного оспаривания |

### Шаг 3. Интерпретация результата

- **Не найден** — зафиксируй дату и время проверки (скриншот/выписка), это часть доказательной
  базы для будущей заявки.
- **Найден, срок активен** — дисквалификация действует для соответствующего закона; репутационный
  риск для коммерческих отношений.
- **Найден, срок истёк** — запись сохраняется в историческом реестре, но дисквалификации для
  текущих закупок нет; репутационный вопрос может сохраняться.

### Шаг 4. Если в РНП — наша компания

#### Обжалование включения

`[сверено 2026-08-27]` Решение комиссии ФАС о включении в РНП — ненормативный правовой акт
государственного органа. Оспаривается в арбитражный суд в порядке ст. 198, 199 АПК РФ в течение
**3 месяцев** со дня, когда участник узнал или должен был узнать о нарушении своего права (общий
срок ст. 198 АПК, а не сокращённый 30-дневный). Пропуск срока без уважительной причины —
основание для отказа в удовлетворении заявления. Основания для успешного оспаривания — процедурные
нарушения при включении либо отсутствие вины участника в нарушении (например, неисполнение по вине
самого заказчика).

Механика самого рассмотрения обращения заказчика комиссией ФАС (сроки уведомления участника,
предоставления возражений до решения о включении) регламентирована подзаконными актами и требует
проверки по первоисточнику на дату дела `[проверить по первоисточнику]`.

#### Пока действует запись

- Коммуникация с коммерческими контрагентами о причине и предпринятых мерах.
- Субподряд через компании без записи в РНП, если бизнес-модель позволяет.
- После истечения 2 лет — автоматическое исключение не наступает мгновенно «в фоне»: проверь запись
  повторно перед подачей следующей заявки.

### Шаг 5. Если в РНП — контрагент/субподрядчик

| Сценарий | Действие |
|----------|----------|
| Субподрядчик в РНП по 44-ФЗ на гос.тендер | не привлекать — заказчик вправе отстранить участника за субподрядчика с активной записью |
| Коммерческий поставщик в РНП | репутационный риск; усиленные заверения и гарантии в договоре, повышенное внимание к due diligence |
| Контрагент в РНП за спорное/незначительное нарушение | зафиксировать объяснение контрагента и факт проведённой проверки |
| Контрагент в РНП за существенное нарушение (крупное неисполнение, признаки недобросовестности) | рекомендация — отказ от сделки или существенное усиление гарантий |

## Чего не делает

- Не подаёт заявление об оспаривании включения в РНП — это outside-адвокат.
- Не проводит комплексную due diligence контрагента (банкротство, судебные споры вне закупок,
  аффилированность) — это `korporativnoe-pravo` и общий due diligence.
- Не отвечает на запросы ФАС в рамках рассмотрения обращения — это outside-адвокат.
