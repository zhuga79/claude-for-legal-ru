# Признаки заточенности закупки

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/gosudarstvennye-zakupki/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/gosudarstvennye-zakupki:cold-start-interview`.

**Двойное применение в зависимости от стороны:**
- **Поставщик-участник** — инструмент решения «участвовать / обжаловать / пропустить» и
  доказательная база для будущей жалобы в ФАС (`zhaloba-v-fas`).
- **Заказчик** — инструмент самопроверки собственной документации до размещения извещения: находка
  здесь снижает риск получить обоснованную жалобу и предписание ФАС. Формулировки ниже даны от лица
  участника — заказчик читает их как чек-лист «не допустили ли мы это сами».

Если включён режим `vedenie-del` — срок на запрос разъяснений и срок на жалобу (до окончания приёма
заявок) пиши в реестр дела, они короткие.

## Индикаторы

### A. Технические показатели

**A1. Брендовая эксклюзивность без «или эквивалент».** Указание конкретной торговой марки/
производителя без слов «или эквивалент» — прямое нарушение ч. 1 ст. 33 44-ФЗ (описание объекта
закупки не должно указывать на товарные знаки, влекущие ограничение количества участников), кроме
случаев, когда иной способ точного описания характеристик отсутствует, — исключение узкое, не
общее правило `[сверено 2026-08-27]`. Для лекарственных препаратов — указание МНН является нормой,
а не нарушением.

**A2. Узкие технические параметры.** Диапазон вида «100,0 ± 0,0 мм» без обоснования — почти
наверняка исключающий признак. Тест: сколько производителей на рынке соответствуют параметру? 1 —
почти наверняка заточенность; 2–3 — сильное подозрение; более 5 — обычно нормально.

**A3. Совокупность параметров.** Каждый параметр в отдельности может быть разумным, но их сочетание
сужает рынок до одного поставщика — эффект тот же, что и прямое указание бренда.

**A4. Эксклюзивные сертификации** — требование сертификата, которым обладает только один
производитель.

### B. Сроки

**B1. Минимальные сроки подачи заявок** — соблюдение формальных минимумов по способу закупки не
исключает подозрения, если минимум использован намеренно, чтобы отсечь неподготовленных участников
`[проверить актуальные минимальные сроки по способу закупки на дату вопроса]`.

**B2. Слишком сжатые сроки исполнения** — исполнить может только тот, кто уже имеет товар на
складе или уже фактически работает на объекте.

### C. Требования к участникам

**C1. Опыт по крайне узкой номенклатуре**, которым в РФ обладает практически один игрок.

**C2. Избыточные финансовые требования** для небольшого по объёму контракта — отсекает малый и
средний бизнес, оставляя действующего исполнителя.

**C3. Географическая привязка** без технологического обоснования необходимости (например,
«производство на территории конкретного региона»).

### D. Цена (НМЦК)

**D1. Искусственно заниженный НМЦК** — отсеивает добросовестных участников, оставляя тех, кто
готов работать в убыток (часто действующий исполнитель с долгосрочными отношениями).

**D2. Искусственно завышенный НМЦК** — может указывать на подготовленную заранее переплату в пользу
конкретного поставщика.

### E. Структурные индикаторы

**E1. История побед у этого заказчика.** Через ЕИС закупки (или `mcp__ru-zakupki__get_customer_history`,
если подключён) — один и тот же поставщик систематически выигрывает у одного заказчика.

**E2. Аффилированность заказчика и вероятного победителя.** Через ЕГРЮЛ (`mcp__ru-egrul__lookup_company` /
`mcp__ru-egrul__search_companies`, если подключён) — совпадение учредителей/директоров (в том числе в
прошлом), бывшие сотрудники заказчика как учредители поставщика, совпадение адреса.

**E3. Избыточно детализированная документация** — специфичные приложения и форматы, которые
предполагают, что только заранее осведомлённый участник знает, как правильно ответить.

### F. Языковые индикаторы

Формулировки ТЗ, понятные только «инсайдеру»; несогласованность частей документации, указывающая на
поспешную либо намеренно запутанную подготовку.

## Workflow

### Шаг 1. Прогон по всем группам

```markdown

- [ ] Брендовая эксклюзивность без «или эквивалент»: [да/нет + где]
- [ ] Узкие параметры без обоснования: [да/нет + список]
- [ ] Совокупность исключающих параметров: [да/нет]
- [ ] Эксклюзивные сертификации: [да/нет]

### B. Сроки
- [ ] Подача на минимально допустимом сроке: [да/нет]
- [ ] Исполнение нереалистично сжато: [да/нет]

### C. Требования к участникам
- [ ] Узкий опыт: [да/нет]
- [ ] Избыточные финансовые требования: [да/нет]
- [ ] Необоснованная география: [да/нет]

### D. Цена
- [ ] НМЦК занижен относительно рынка: [да/нет]
- [ ] НМЦК завышен относительно рынка: [да/нет]

### E. Структурные
- [ ] История побед конкретного поставщика у заказчика: [N побед / M закупок за 3 года]
- [ ] Аффилированность заказчик–участник: [да/нет/не проверено]
- [ ] Документация с признаками pre-coaching: [да/нет]

### F. Языковые
- [ ] Странности формулировок: [да/нет]
```

### Шаг 2. Вероятностная оценка

- 0–2 сработавших индикатора — **низкая** вероятность, обычная закупка.
- 3–5 — **средняя** — есть основания для запроса разъяснений.
- 6 и более — **высокая** — почти наверняка заточена.

*Это эвристика для приоритизации, не юридическая квалификация. Правовая оценка нарушения —
конкретная норма ст. 33/17 ФЗ-135 «О защите конкуренции» применительно к найденному факту, не
сумма баллов.*

### Шаг 3. Стратегия по уровню

**Низкая** — участвовать, если пройден `proverka-dopuska-k-zakupke`.

**Средняя** — запросить разъяснения (ст. 42 44-ФЗ, срок ответа заказчика зависит от способа
закупки `[проверить актуальный срок ответа на дату вопроса]`); ответ становится частью
документации и обязателен для всех участников — либо снимает подозрение, либо подтверждает
основание для жалобы.

**Высокая** — варианты: (1) пропустить закупку, не тратя ресурсы; (2) подать жалобу в ФАС
**до окончания срока подачи заявок** — самый эффективный момент, см. `zhaloba-v-fas`; (3)
участвовать несмотря на признаки — иногда действующий исполнитель отсеивается сам (попадание в
РНП, отказ от подписания контракта), и закупка открывается для остальных.

### Шаг 4. Для стороны заказчика — иной вывод

Если запускается заказчиком для самопроверки: находка на уровне «средняя»/«высокая» — сигнал
скорректировать документацию (добавить «или эквивалент», расширить диапазон параметров, обосновать
узкое требование по существу) **до** размещения извещения, а не после получения жалобы. Пересчёт
после получения предписания ФАС обходится дороже — срыв срока закупки, репутационные издержки.

[участвовать / запрос разъяснений → возможная жалоба / пропустить / для заказчика — скорректировать документацию]

## Чего не делает

- Не подаёт жалобу — это `zhaloba-v-fas`.
- Не проводит углублённую проверку аффилированности — это due diligence / `korporativnoe-pravo`.
- Не ведёт рассмотрение дела в ФАС.
