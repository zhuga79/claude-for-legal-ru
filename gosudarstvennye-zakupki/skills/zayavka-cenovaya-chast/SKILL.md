# Заявка — ценовая часть

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/gosudarstvennye-zakupki/CLAUDE.md`. Файла
нет или `[ЗАПОЛНИТЬ]` — стоп, направь на `/gosudarstvennye-zakupki:cold-start-interview`.

Сторона поставщика-участника. Этот скилл считает **цену и её последствия по 44-ФЗ**, не налоговые
последствия сделки (НДС, налог на прибыль с маржи заявки) — за расчётом налоговой нагрузки конкретной
цены обращайся к `nalogovoe-pravo`, здесь только структура цены для целей закупочной процедуры.

## Pre-flight

- НМЦК известен из документации.
- Способ определения поставщика: аукцион (цена определяется в ходе торгов) / конкурс (цена — часть
  единой заявки).
- `proverka-dopuska-k-zakupke` и `proverka-dokumentacii-zakupki` пройдены.
- Финансовая модель себестоимости выполнена (вне этого скилла — финансовый блок).

## Workflow

```markdown
- **Цена безубыточности: [сумма]**
- **Целевая цена заявки:** себестоимость × (1 + целевая маржа / 100)
```

### Шаг 3. Антидемпинговый анализ (ст. 37 44-ФЗ)

`[сверено 2026-08-27]` Порог — снижение цены на **25% и более** от НМЦК.

```markdown
## Зона антидемпинга

- НМЦК: [сумма]
- Порог 25%: [сумма × 0,75] — предложения ниже этой суммы попадают в антидемпинговую зону

### Если предложение ≥ 75% от НМЦК (обычная зона)
Стандартное обеспечение исполнения, обоснование цены не требуется.

### Если предложение < 75% от НМЦК (антидемпинговая зона)

Контракт с таким участником заключается только после предоставления обеспечения исполнения,
увеличенного **в 1,5 раза** от размера, установленного в документации, но не менее 10% НМЦК/цены
контракта `[сверено 2026-08-27]`.

При НМЦК от 15 млн ₽ дополнительно:
- обязательное представление подтверждения добросовестности либо документального обоснования
  реалистичности предложенной цены (ст. 37 ч. 2) — например, прямые договоры на закупку сырья по
  цене ниже рыночной, собственное производство, подтверждённая оптимизация издержек;
- авансирование по этому контракту не предоставляется.

При НМЦК до 15 млн ₽ участник вправе представить документы о добросовестности вместо повышенного
обеспечения — конкретный набор допустимых подтверждений и точный механизм выбора между этими
опциями сверить по актуальной редакции ст. 37 на дату закупки
`[проверить по первоисточнику]`.

## Рекомендация
[какая стратегия предпочтительна с учётом нашей финансовой модели и конкуренции]
```

### Шаг 4. Стратегическое позиционирование цены

| Паттерн | Логика | Риск |
|---|---|---|
| Победа любой ценой | Минимально возможная цена, включая антидемпинговую зону, ради опыта/присутствия на рынке | Убыточность контракта, повышенное обеспечение, репутационный риск при недоборе качества |
| Оптимальная маржа | Цена чуть ниже ожидаемой медианы по рынку | Средняя вероятность победы при типичной конкуренции |
| Высокая маржа, низкая вероятность | Цена близко к НМЦК | Имеет смысл для узкоспециализированных закупок с малой конкуренцией |
| Отказ от участия | Ни одна цена не даёт приемлемой маржи | Не «проигрыш» — иногда правильнее приберечь ресурсы для другой закупки |

### Шаг 5. Черновик ценовой части

#### Аукцион

Заявка содержит только согласие с условиями — сама цена формируется в ходе торгов на ЭТП (шаг
понижения — фиксированный процент от НМЦК, установленный документацией
`[проверить актуальный минимальный шаг на дату вопроса]`). Работа этого шага — не текст заявки, а
стратегия торгов.

#### Конкурс

```markdown
# ЦЕНОВОЕ ПРЕДЛОЖЕНИЕ
# участника закупки № [номер]
# [Наименование участника, ИНН]

## Общая цена контракта
Предлагаемая цена: [сумма прописью] руб. ([цифрами]) с НДС [сумма].

## Разбивка по позициям (если применимо)

|---|--------------|------------|--------------------|---------|-------|----------------|
| 1 | [...] | [...] | [...] | [...] | [...] | [...] |
| **Итого** | | | | | | **[сумма]** |

## Условия оплаты

[Электронная подпись, ФИО руководителя, дата]
```

### Шаг 6. Если предложение попадает в антидемпинговую зону — обоснование цены

```markdown
# ОБОСНОВАНИЕ ЦЕНЫ
(в порядке ст. 37 ч. 2 44-ФЗ)

Представляем обоснование предлагаемой цены [сумма], которая ниже НМЦК [сумма] на [%].

## Источники низкой себестоимости
- Прямые закупки у производителя без посредников — договор № X от ДД.ММ.ГГГГ (приложение 1),
  сравнение с рыночной ценой
- Собственное производство ключевых компонентов — описание, сертификаты
- Оптимизация логистики — собственная транспортная служба, расчёт маршрута

## Подтверждение возможности исполнения
- Опыт исполнения аналогичных контрактов (приложение — перечень)
- Финансовые ресурсы для авансирования собственными средствами (приложение — банковская выписка)
- Кадровые ресурсы (приложение — штатное расписание)

## Подтверждение качества
- Сертификаты системы менеджмента качества (если есть)
- Контроль качества на каждом этапе, полные гарантийные обязательства

## Заверение
Подтверждаем, что предлагаемая цена позволяет исполнить контракт в полном объёме с соблюдением
условий ТЗ.

[Подпись, дата]
```

## Чего не делает

- Не выполняет полное финансовое моделирование себестоимости — это финансовый блок компании.
- Не считает налоговые последствия цены — это `nalogovoe-pravo`.
- Не подаёт цену через ЭТП — действие самого участника.
- Не ведёт переговоры с заказчиком после подведения итогов.
