# /otpusk-zapis

Быстро добавляет одну запись в файл учёта отпусков и помечает очевидные проблемы. Полный
анализ (график, накопленные остатки, риски к проверке ГИТ) — `/trudovoe-pravo:otpuska-uchet`.

## Контекст дела

Прочитай `~/.claude/plugins/config/claude-for-legal-ru/trudovoe-pravo/CLAUDE.md`. Файла нет
или остались `[ЗАПОЛНИТЬ]` — стоп: «Плагину нужна настройка, запусти
`/trudovoe-pravo:cold-start-interview`».

Если включён `vedenie-del` и есть активное дело — пиши в файл учёта в папке дела (тот же, что
читает `/trudovoe-pravo:otpuska-uchet`). Режим выключен — уточни у пользователя, куда вести
файл. Не заводи учёт в диалоге.

## Порядок работы

### Шаг 1. Спроси минимум

- **Работник** — Ф.И.О. или обезличенно, табельный номер.
- **Вид** — ежегодный основной / ежегодный дополнительный (с основанием) / по беременности и
  родам / по уходу за ребёнком до 1,5 / по уходу до 3 лет / без сохранения зарплаты / учебный /
  донорские дни / нетрудоспособность / иной.
- **Период** — с ДД.ММ.ГГГГ по ДД.ММ.ГГГГ.
- **Основание** — приказ № __ / листок нетрудоспособности № __ / заявление от __ / медицинское
  заключение.
- **По графику отпусков** — да / нет.

### Шаг 2. Определи применимость пособия СФР

`[таблица сверена 27.08.2026 по ТК и ФЗ от 29.12.2006 № 255-ФЗ; размеры пособий — проверить на
год применения]`

| Вид | Пособие СФР | Заметки |
|---|---|---|
| Ежегодный основной (ст. 115 ТК) | нет — оплата работодателем (отпускные) | не менее 28 календарных дней, по графику |
| Ежегодный дополнительный (ст. 116–119 ТК) | нет — оплата работодателем | основание: СОУТ / ненормированный день / север / особый характер работы |
| По беременности и родам (ст. 255 ТК) | да — средний заработок, не зависит от стажа | 140 / 156 / 194 календарных дня `[проверить]` |
| По уходу за ребёнком до 1,5 лет (ст. 256 ТК) | да — 40% среднего заработка | сохраняется при досрочном выходе на работу (ФЗ от 19.12.2023 № 614-ФЗ) |
| По уходу за ребёнком до 3 лет (ст. 256 ТК) | нет (после 1,5 лет пособие по уходу не выплачивается) | место работы сохраняется, засчитывается в стаж |
| Без сохранения зарплаты (ст. 128 ТК) | нет | для обязательных категорий — в пределах лимита дней в году |
| Учебный (ст. 173–176 ТК) | нет — оплата работодателем при условиях | только по аккредитованной программе, образование соответствующего уровня впервые |
| Донорские дни (ст. 186 ТК) | нет — оплата работодателем по среднему заработку | день сдачи крови + дополнительный день отдыха |
| Нетрудоспособность (ст. 183 ТК) | да — с 4-го дня болезни работника (первые 3 дня — работодатель) | электронный листок; 60 / 80 / 100% по стажу |

### Шаг 3. Добавь запись

```markdown
## Запись от [ДД.ММ.ГГГГ ЧЧ:ММ]

- **Работник:** [Ф.И.О. или обезличенно] (таб. № [...])
- **Вид:** ежегодный основной отпуск
- **Период:** 15.06.2026 — 28.06.2026 (14 календарных дней)
- **Основание:** приказ № 45 от 01.06.2026; заявление от 25.05.2026
- **По графику отпусков:** да
- **Пособие СФР:** не применимо
- **Заметки:** [присоединение к другому периоду, возможность отзыва и т. п.]
- **Внёс:** [пользователь]
```

### Шаг 4. Пометь очевидные проблемы

- **Ни одна часть ежегодного отпуска в текущем году не достигает 14 календарных дней** —
  ч. 1 ст. 125 ТК требует хотя бы одну часть не менее 14 дней.
- **Работник извещён о начале отпуска менее чем за 2 недели** — ч. 3 ст. 123 ТК.
- **Отпуск вне графика без оформленного соглашения о переносе** — ст. 123, 124 ТК.
- **Замена ежегодного отпуска компенсацией в части, не превышающей 28 дней** — запрет ст. 126.
- **Электронный листок нетрудоспособности не подтверждён в СФР** — отметить для проверки.
- **Отпуск по беременности и родам оформлен со значительной задержкой относительно 30 недель
  беременности** — часть периода может быть утрачена, уточнить.

## Чего не делать

- Не готовить приказ, записку-расчёт, график — это кадровая служба.
- Не рассчитывать отпускные, средний заработок, размер пособия — это бухгалтерия и СФР.
- Не подавать сведения в СФР — это кадровая служба.
- Не делать полный анализ соблюдения графика и лимитов — это `/trudovoe-pravo:otpuska-uchet`.
- Не давать налоговую квалификацию выплат — зона `tax-advisor`.
